Status Trio — нативное приложение состояния для macOS, которое объединяет Wi-Fi, батарею и громкость в одном компактном настраиваемом значке, отображаемом в строке меню, в Dock или в обоих местах. Его панель идёт дальше значка: панель Wi-Fi для сетей поблизости и сведений о соединении, панель Bluetooth для сопряжённых устройств, страница «Сведения об аккумуляторе» и звуковые устройства, которые воспроизводят звук. Приложение вдохновлено объединённым значком строки состояния iPhone Duo для Wi-Fi, батареи и сотовых данных, адаптированным для Mac: громкость заменяет сотовые данные.

> Status Trio — независимый проект, не связанный с Apple.

## Возможности

- **Один значок, три сигнала** — батарея, Wi-Fi и громкость используют один значок в строке меню, в Dock или в обоих местах, а устройство Bluetooth, воспроизводящее звук, может занять центральное место со своим собственным символом.
- **Bluetooth** — во время воспроизведения индикатор громкости становится синим. Панель перечисляет сопряжённые устройства, по которым можно щелкнуть, чтобы подключить или отключить их, показывает уровни заряда по умолчанию и остаётся выключенной, пока вы её не включите.
- **Батарея** — процент, зарядка или питание от сети, время до полного заряда и цвет при низком заряде. Откройте строку, чтобы увидеть номинальную мощность адаптера, напряжение, ток, число циклов и «Режим энергосбережения».
- **Wi-Fi** — сеть, к которой вы подключены, и уровень сигнала. Откройте раздел, чтобы увидеть сети поблизости, посмотреть сведения о соединении или выключить Wi-Fi. Переключение между сетями происходит в панели Wi-Fi «Системных настроек».
- **Громкость** — уровень, отключение звука и устройство вывода, отображаемые точками или дугой. Прокручивайте всю панель или только регулятор и выберите, в какую сторону громкость увеличивается.
- **Настройте под себя** — размер значка, масштаб символов, толщина кольца, цвета состояний и то, какие разделы показывает панель, в нужном вам порядке.
- **Строка меню, Dock или оба** — а значок в Dock может следовать системному стилю или всегда оставаться тёмным либо светлым.
- **Нативно в macOS** — щелчок левой кнопкой открывает панель, правой — меню, а руководство при первом запуске объясняет каждую часть значка. Ethernet, точка доступа или общий доступ к интернету могут сохранять символ Wi-Fi, если вы так предпочитаете.
- **Всегда актуально** — состояние поступает из системных событий, а резервным вариантом служит редкий опрос; Sparkle обновляет приложение через подписанный канал.
- **Также включено** — двенадцать языков и необязательная настройка **Запускать при входе**.

## Установка

Установите официальный Cask Homebrew:

```bash
brew install --cask status-trio
```

Обновление установки Homebrew:

```bash
brew upgrade --cask status-trio
```

Или скачайте последний `StatusTrio-*.dmg` из [GitHub Releases](https://github.com/lingyired/status-trio/releases/latest), откройте его и перетащите `Status Trio.app` в `/Applications`.

Официальная версия подписана Developer ID и нотарифицирована Apple. После установки откройте её обычным способом; удалять атрибуты карантина не нужно. Обновления в приложении используют Sparkle с проверкой подписи EdDSA.

## Управление вводом и звуком

- **Значок источника ввода**: текущую раскладку можно показывать в центре значка строки меню и Dock. Выберите её в **Настройки › Сеть**; в панели можно выбрать включённый источник ввода и переключиться на него.
- **Глобальное сочетание клавиш**: назначьте в **Настройки › Основные**, чтобы открывать или закрывать панель из другого приложения. По умолчанию не назначено.
- **Управление Bluetooth**: включение и выключение Bluetooth, подключение устройств и выбор режимов прослушивания совместимых AirPods и HUAWEI FreeBuds. Необязательные строки заряда устройств Apple настраиваются в разделе Bluetooth; доступность зависит от устройства и соединения.
- **Аудиовход и выход**: выбор динамиков и микрофонов, настройка уровней. Динамики совместимых внешних мониторов управляются через DDC; поддержка зависит от оборудования и подключения.
- **Зарядка и оформление**: эффекты зарядки в строке меню и Dock. В macOS 26 и новее значок в Finder и Launchpad также следует светлому или тёмному оформлению системы.

## Новое в main (ещё не выпущено)

Эти функции есть в исходном коде `main`, но не в текущей публичной версии GitHub / Homebrew **1.7.5**:

- **Потоки мощности и влияние CPU на энергопотребление**: оценки входной мощности зарядного устройства, зарядки батареи и питания системы. Необязательный список ранжирует до пяти приложений по энергии CPU, а при отсутствии счётчиков — по активности CPU. Это не полное потребление и не системный список macOS. Включение запускает периодические фоновые замеры, выключение останавливает их. [Подробнее](docs/battery-power-flow.md).
- **Зарядить полностью сейчас и отменить**: по умолчанию выключено, доступно на поддерживаемых Mac с чипом Apple и macOS 26.4 или новее. Использует закрытый интерфейс PowerUI для отмены лимита. **После зарядки или переподключения питания лимит может остаться на 100% и не восстанавливается автоматически.** Отмените операцию для запроса восстановления либо проверьте и восстановите лимит в Системных настройках. Поведение зависит от macOS. [Поведение и проверка](docs/charge-to-full-now-poc.md).

## Звук Bluetooth

Когда звук воспроизводится через Bluetooth, два переключателя в разделе **Настройки › Bluetooth** позволяют центральному символу стать собственным символом этого устройства — AirPods, наушники, динамики и другие устройства предоставляют свои символы — и разрешают точкам или дуге громкости становиться синими. Оба параметра по умолчанию выключены. **Приоритет ошибок сети**, включённый по умолчанию, сохраняет значок сети, пока само подключение испытывает проблемы:

<p align="center">
  <img src="screenshots/menu-bar-airpods.jpg" width="1000" alt="Значок Status Trio в строке меню с символом AirPods при подключённых AirPods и открытой панелью состояния">
</p>

Строка Bluetooth в панели сообщает состояние в реальном времени: имена подключённых устройств и, для AirPods, заряд левого, правого наушника и зарядного кейса. Панель Bluetooth перечисляет сопряжённые устройства и их состояние подключения: щелкните по устройству, чтобы подключить его, а по подключённому — чтобы отключить; клавиатуры, мыши, трекпады и геймпады сначала запрашивают подтверждение в самой строке. Она по умолчанию выключена, включается в разделе **Настройки › Панель состояния** и запрашивает разрешение на Bluetooth при первом использовании. Раздел **Настройки › Bluetooth** также определяет, считывается ли уровень заряда, перечисляет сопряжённые устройства, чтобы вы могли перетащить их в нужном порядке и задать, сколько их показывать, и масштабирует значок Bluetooth от 100% до 180%.

## Требования

- macOS 13 как целевая версия (проверка в Ventura ожидается) для работы приложения
- Инструментарий Swift 6 с macOS 26 SDK (Xcode 26 или новее) для его сборки. Сборка со
  старым SDK незаметно даёт панель в оформлении до Tahoe, поэтому `scripts/build-app.sh`
  завершается ошибкой, если SDK старее 26.

## Запуск из исходного кода

```bash
git clone https://github.com/lingyired/status-trio.git
cd status-trio
swift run StatusTrio
```

## Сборка локального приложения

Соберите пакет приложения с ad-hoc подписью и запустите его:

```bash
bash scripts/build-app.sh release
```

Пакет создаётся в `dist/StatusTrio.app`. Чтобы выполнить сборку, не завершая и не запуская существующий экземпляр, выполните:

```bash
bash scripts/build-app.sh release no-open
```

Пакет с ad-hoc подписью предназначен для локального личного использования. Gatekeeper может отклонить его, если пакет переносится вместе с метаданными карантина.

## Использование

- **Щелчок левой кнопкой** по значку в строке меню или в Dock открывает панель состояния.
- **Щелчок правой кнопкой** по любому из этих значков открывает нативное меню, включая версию и команду завершения.
- Выберите строку Wi-Fi или батареи в панели, чтобы открыть её страницу: сети поблизости и сведения о соединении либо «Сведения об аккумуляторе». Строка Bluetooth перечисляет свои сопряжённые устройства прямо в панели — щелкните по устройству, чтобы подключить или отключить его, — и показывает кнопку «Развернуть», когда они не помещаются все.
- Откройте **Настройки**, чтобы выбрать, где показывается значок (строка меню, Dock или оба места), и изменить его размер, цвета, толщину кольца, разделы панели и их порядок, поведение регулировки прокруткой, язык, проверку обновлений и параметр **Запускать при входе**.
- В любой момент снова откройте руководство **Знакомство со значком** через **Настройки › Значок приложения › Открыть руководство**.
- Разрешите показ имени текущей сети Wi-Fi, когда появится запрос; macOS запрашивает доступ к геолокации для этой необязательной детали.

## Известные ограничения

Две границы, которые macOS и этот проект проводят намеренно. Обе описаны в разделе [Известные ограничения](docs/known-limitations.md).

- **Переключение между сетями происходит в «Системных настройках».** Выбор сети в панели открывает панель Wi-Fi; Status Trio никогда не читает и не хранит пароли Wi-Fi, потому что macOS не предоставляет публичного API для подключения с сохранённым паролем, и любой другой вариант заканчивается тем, что приложение хранит их у себя.
- **Управление лимитом зарядки зависит от версии.** Версия 1.7.5 открывает Системные настройки. Необязательная функция `main` использует закрытый интерфейс; для запроса восстановления нужна явная отмена. [Подробнее](docs/charge-to-full-now-poc.md). Режим энергосбережения использует отдельный [необязательный привилегированный helper](docs/privileged-helper.md).

## Языки

По умолчанию Status Trio следует предпочитаемому языку macOS и включает English, 简体中文, 繁體中文, 日本語, 한국어, Español, Français, Deutsch, Italiano, Português (Brasil), Русский и العربية.

## Конфиденциальность

Status Trio читает состояние системы локально. Анонимная статистика отправляется собственному сервису только после включения; при обновлении она выключена, при новой установке запрашивается выбор. Передаются случайный ID установки, версии приложения и macOS, язык и положение значка, без имён, аккаунтов, данных сети и аппаратных идентификаторов. См. [телеметрию и конфиденциальность](docs/privacy-telemetry.md). Приложение не читает и не хранит пароли Wi-Fi и не запрашивает Связку ключей. Геопозиция необязательна для имени и сведений Wi-Fi; доступ к Bluetooth запрашивается при включении панели. В `main` необязательное управление полной зарядкой использует закрытый интерфейс PowerUI только после включения; ограничения описаны ранее.

## Разработка

Запустите набор тестов:

```bash
bash scripts/verify-local.sh quick BatteryMonitorTests
bash scripts/verify-local.sh docs
bash scripts/verify-local.sh full
```

Запустите выборочный фильтр XCTest через вспомогательный скрипт:

```bash
bash scripts/test.sh BatteryMonitorTests
```

Чтобы собрать приложение из worktree рядом с основной установкой:

```bash
bash scripts/build-worktree.sh release
```

Вспомогательный скрипт выводит идентификатор пакета для разработки и отображаемое имя из текущей ветки. Оба значения можно переопределить:

```bash
BUNDLE_ID=com.lingsmbp.StatusTrio.dev.settings-redesign \
APP_NAME="Status Trio (Settings Redesign)" \
bash scripts/build-worktree.sh release
```

Блокировка единственного экземпляра привязана к идентификатору пакета, поэтому сборки с разными идентификаторами могут работать одновременно.
