# 1.9.0 审查问题修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修正 v1.8.0 以来确认的 8 项问题及可选后端缺陷，解决全量验证失败后，交付 1.9.0 非发布 CI 测试包和完整中文更新日志。

**Architecture:** 沿用 SettingsStore 的持久化、单一 PowerSamplingService 的需求集合和现有 monitor/coordinator 分层。设置迁移显式落盘；面板释放自己登记的采样需求；显示器拓扑事件失效旧连接；错误状态从后端传到展示层。每项补边界回归，不重构无关模块。

**Tech Stack:** Swift 6.4、Swift Testing/XCTest、Combine、AppKit/SwiftUI、SPM、现有 shell 验证脚本和 GitHub Actions。

**Spec:** [本次审查报告与复现证据](../../reviews/2026-11-01-v1.9.0-review.md)。候选为 `296338508d055f50906cb3afaf8ec82d615d13de`，基线为 `v1.8.0`。

## Global Constraints

- 用户已于 2026-11-01 授权委派子任务执行修复，指定 `group/smart-auto` 和 `reasoningEffort=high`；本次在隔离工作树实施、测试和审查。

- Menu Bar / Dock 使用同一场景和设置来源；不添加无主的后台计时器。

- 不削弱测试、跳过失败或将重试偶然通过视为通过；静态指纹不能简单接受本次失败的 SHA。
