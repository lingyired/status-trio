## 行为要求

1. 蓝牙按实际消费者启停：可见蓝牙分区、确实依赖配对列表的图标、蓝牙设置页面、可见音频列表的必要能力、已明确启用的后台设备电量需求。全部关闭时，不因打开通用状态面板激活 CBCentralManager、启动 paired-device profiler 或定时轮询。不扩大授权；未授权时仅显式用户操作能请求权限。关闭其中一个消费者不得停止其他消费者，睡眠/唤醒及迟到回调保持正确。
2. 没有消费者时清理可重新读取的设备/电量/动作/报告缓存，不能删除用户授权、选择、隐藏顺序、自定义图标或已存设备元数据。共享 profiler 报告不能在另一读者使用时失效。
3. 面板隐藏分区不继续做无用 mapping 和专属订阅；未打开详情页面不预先构建大列表。音频区域所需 AirPods listening mode 是独立消费者，不能因为蓝牙分区隐藏而失效。重新开启分区立即显示最新值，保留本地化和错误状态。
4. 普通面板关闭立即暂停 presentation 订阅，完整 SwiftUI hosting 内容仅保留5秒供快速重开；超时后释放 hosting 及可重建大数组。详情面板仍立即释放。快速重开先恢复最新状态，已取消的旧释放任务不得清掉新窗口。内存压力只回收不可见内容。
5. 预览专用图片、decode/mask、scratch 仅在没有对应可见使用者时回收；不能简单在面板关闭时清空活动 Dock/menu 动画帧、用户仍看着的设置/引导预览，也不能每tick重建或新增周期性清理。用户设置不变，当前图像保持。
6. 峰值调查交付可复用只读曲线采样工具，记录 footprint/RSS/累计峰值、单调时间、精确进程identity及可见窗口数量。不采集窗口标题/内容。记录启动/展开/关闭/重开阶段，不能把累计峰值当阶段峰值；未复现342MiB时交付未复现证据，不写猜测性产品补丁。

## 验收边界

保持 macOS13、SDK>=26；不使用 isolated deinit/weak let/实验隔离开关。菜单栏与Dock一致、Issue30可见墨迹居中回归不放宽，36帧/20FPS/心跳/burst/ReduceMotion不变。所有内存预算是像素/缓存预算，不等同于进程释放承诺。2026-10-21 同步 main 后遵循当前本地优先规则：模块逐项测试、独立审查和最终整合树的 `bash scripts/verify-local.sh full`；正式发布环境为 Xcode27，普通开发及合并不要求远端CI。只有维护者明确批准时才运行可选远端诊断。真实蓝牙硬件/多显示器/不同OS不能由mock冒充。
