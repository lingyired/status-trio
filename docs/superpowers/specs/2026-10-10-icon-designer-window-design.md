## 3. 主窗口与模拟工具窗口

### 主设计器

初始内容尺寸 1120×800 pt，最小 900×680 pt；根据当前屏幕 visibleFrame 缩小初始尺寸，不能使标题栏离屏。可调整大小；1280×800 屏幕和更大屏幕都能使用。主窗口左列 44%、右列 56%，使用边界约束防止标签/卡片挤压。

左列常驻：240–300 pt 编辑放大图、真实菜单栏尺寸对照、128 pt Dock 预览、显示原因，以及 `预览数据：实时 / 模拟`、`场景`、`编辑数据…`。放大图不是宣称菜单栏实际尺寸。点击三个元素或右侧 tabs 都只改变当前编辑位置；选中标记不改变实际图标颜色。解释靠近图标，不放顶部固定说明栏。Dock 本身单独渲染，不能直接用菜单栏图标缩放冒充。

右列：外环 / 中间 / 底部；依次显示内容、当前来源规则、折叠的不可用时备用来源、外观。右侧独立滚动，不能让大量设置把左侧预览推走。顶端轻量标题/预设入口，底部撤销和恢复当前元素；恢复全部默认放更多菜单。显示位置、菜单栏图标渲染范围和 Dock 图标背景由外部应用图标页统一设置；独立设计器只编辑图标组成，不重复嵌入这组共用显示设置。图标指南入口仅保留在外部应用图标页，独立设计器不显示重复入口。整体尺寸仍按图标设计器尺寸规范编辑。

### 模拟数据编辑器

`编辑数据…` 切换为模拟模式并打开唯一 `NSPanel`，初始 380×520 pt，最小 340×360 pt。浮动级别只作用本 App，`hidesOnDeactivate = true`；支持键盘输入和关闭。不使用持续盖住其他 App 的全局 overlay，不创建新的 Dock 图标。

面板首次出现在主窗口侧边的可见屏幕范围；空间不足时放在主窗口前方的可见区域，不移动主窗口。分别保存主/工具窗口 frame autosave 名称。再次点击入口复用并前置同一个 panel。关闭 panel 不清除样例；关闭主设计器同时关闭 panel；App 本次运行内重开设计器保留样例与模式，重新启动 App 回到实时模式。工具窗口可内部滚动，但**开关或编辑它不能改变主窗口大小、滚动区域或位置**。

工具窗口没有应用/保存按钮：样例即改即预览，并永久标注“仅用于预览，不改变设备或实际图标”。实时模式下隐藏模拟场景和编辑控件，仅提供“使用模拟数据…”；切回实时停止使用样例，但保留样例值供再次切换。

## 4. 数据源和选项组织

### 外环

Mac 电池、AirPods 电量、不显示。Mac 保留百分比、文字大小、低电量阈值、充电相关已有有效规则；首次把主来源切换为 AirPods 且没有备用来源时，默认使用 Mac 电池作为备用；已有备用来源和用户显式清空的选择都保留。AirPods 保留设备选择、后台读取选择和单/双环规则，新设计器及恢复外环默认使用双环。用户显式选择的单环继续保留；经典配置和旧 V1 payload 缺少该字段时仍按单环解码。AirPods 不提供充电动效。实际监控的开关是正式配置，不进入模拟面板。

### 中间

顶层只有网络状态、蓝牙设备、Mac 电量百分比、不显示。

蓝牙设备内分：
1. 当前蓝牙音频输出：跟随系统当前输出，不主动切换音频设备。
2. 指定在线蓝牙设备：列表按音频设备/其他设备分组，仅使用现有真实在线目录；按标准化地址持久化，不按名称或列表下标。

指定 AirPods/扬声器也是音频目标，展示适用的符号定制、使用音量颜色和网络异常优先；键盘/鼠标不展示音频专属选项。音量颜色改变中间音频图标，不能覆盖底部独立外观。固定蓝牙符号归为图标样式，不是顶层来源。符号选择保留 macOS 13 fallback 与既有自定义图标。

设备离线时保留选择，并显示“当前不可用”，执行备用来源；不能擅自选下一台设备，也不能触发 connect/pair/GATT。无权限时显示权限状态和既有系统设置入口，不能把历史缓存说成在线设备。模拟设备与真实设备必须明显区分，模拟地址不能写入真实选择。

未来输入法图标、中间音量只保留扩展点，**本次不实现、不出现可点击的未支持入口**。

### 底部与共用外观

系统音量/不显示，点/弧表现，颜色、线宽。自动/固定/状态颜色使用原生 ColorPicker。中间只有一个符号大小入口，保留旧配置的实际尺寸；首次明确编辑大小时写入一个可选的最终倍率（0.5–6.0），直接应用到中间 symbol/text，不再叠乘来源倍率。旧配置缺少此字段时继续旧计算，新字段默认 nil，打开界面不迁移。主/备用来源使用相同最终倍率；不得重新引入 Wi-Fi 第二个大小控制。主/备用来源共用这个元素的外观；备用来源行为在折叠区单独编辑，不能修改主来源规则。

> **规范尺寸替代（2026-10-12）：** 本段旧的中心尺寸 UI 与“首次编辑写入最终倍率（0.5–6.0）”规则已被 [Icon Designer sizing standard](../../icon-sizing-standard.md) 取代。所有中心来源统一使用 100–180% 可见尺寸百分比；外环与底部弧/点笔画统一使用 80–120% 相对百分比。旧倍率字段和值域仅为存储兼容及未显式编辑时的旧渲染保留，不再定义 UI 或首次编辑行为；不得自动迁移旧值。

### 中心按状态颜色角色（2026-10-12）

中心颜色的“按状态”角色只列出当前主来源、有效备用来源及可达网络异常覆盖实际会输出的 `IconColorRole`；同一角色只出现一次，但标签聚合它适用的来源/条件。Wi‑Fi 常规网络状态（未关联、关闭、无互联网及非零信号等）都使用 primary；只有已连接 Wi‑Fi 被 RSSI 规则量化为 0 格（RSSI ≤ −89 dBm 或不可用）使用 inactive，不得命名为“断开”。蓝牙音频未启用音量颜色时只使用 Bluetooth；启用后，量化音量大于 0 使用 Bluetooth，静音、音量为 0 或音量不可用使用 primary。蓝牙音频的网络异常优先覆盖只增加“网络异常覆盖”下的网络 primary 角色。指定非音频设备及固定蓝牙 glyph 只使用 Bluetooth；Mac 电量百分比只使用 primary；none 无中心颜色角色；automaticLegacy 仅暴露兼容渲染实际可能产生的 primary、Wi‑Fi 0 格 inactive 和 Bluetooth 角色。有效备用来源的角色同样纳入并标注为备用；primary 为 none 时按配置规范清除备用。仅一个可达角色时隐藏状态菜单，颜色行直接显示该角色实际含义；说明文字仅在中心采用“按状态”颜色时显示，并使用用户可理解的场景描述，不在帮助文案中暴露颜色角色名、RSSI 或量化规则。筛选只影响编辑器可选项，不迁移、清除或重写已保存的颜色覆盖；菜单栏与 Dock 仍通过共同解析后的 scene 使用同一颜色角色。

## 5. 模拟数据：绑定来源，不绑定元素

一个共享、仅内存的 session，持有 mode、scenario、selectedSlot 与 source-keyed samples；主/工具窗口观察同一个 session。以稳定来源 ID 标识 Mac 电池、AirPods、网络、蓝牙目标、系统音量，不以 tab、窗口或数组位置标识。

工具窗口仅列出当前配置的主/备用来源和规则依赖的数据（例如音频配色依赖音量）；同一 Mac 电量用于外环及中间数字时只有一份样例。切换编辑元素轻量提示相关数据行，不复制或重置样例。隐藏的数据保留，换回来源恢复之前数值。

Mac：电量、是否存在、充电状态。AirPods：左右耳是否可用、电量 0–100、双耳/仅左/仅右/均不可用 presets。默认样例：Mac 存在、76%、未充电；AirPods 双耳可用、左73%右68%；网络正常 Wi-Fi；蓝牙在线音频耳机；系统音量62%、未静音、可用。网络可选：正常/无互联网/关闭/有线/热点/临时/共享。蓝牙：模拟目标在线与否、音频/非音频类型、样例符号。音量：0–100、静音、是否可用。

场景是一次性样例预设，选择场景填充共享样例；之后手动编辑数值实际生效，不能被固定 scenario 分支持续覆盖。非法数值 clamp；NaN/无穷不崩溃。单耳在线双环镜像可用一耳，两耳均不可用执行备用来源。

模拟模式构造完整确定性的 `IconResolutionInputs`，调用真实 CompositionResolver；不沿用未声明的实时字段。模拟权限状态只改样例，不调用系统授权。既有真实权限 banner 仍基于真实权限状态。模拟输入绝不传给 StatusBarController、AppIconController 或系统监控。

## 6. 默认、旧配置、撤销

UI 不再提供“自动兼容”来源。内部 `.automaticLegacy` 必须继续可解码；打开窗口/选择 tab/打开模拟面板不迁移或写入偏好。

旧配置保留原始值及真实渲染，显示非可选说明“原有显示规则已保留；选择新内容后替换”，不伪装已经迁移为某个新来源。`.pinnedBluetoothGlyph` 同样归在蓝牙卡片内：已有设备地址映射为该目标；无地址的旧静态符号显示“尚未绑定设备”，保留图案直到用户明确选择。

明确的新默认组合：外环 `.systemBattery`，中间 `.network`，底部 `.systemVolume`，备用均 nil，behavior/appearance 使用现有 classic 值；设计器明确恢复中心时叠加 `normalizedSizePercentage = 1.0`，而 legacy/classic 配置仍保持 nil。此操作不恢复 `.automaticLegacy` 主来源。默认网络不隐式被蓝牙替换。只在用户确认“恢复默认”后应用；不改变既有安装首次打开的图标。

恢复当前元素只恢复该元素 composition、相关行为与 appearance，不清除其他元素、placement、实际设备许可或共享模拟样例。恢复全部仅恢复三个元素的图标配置，不重置语言、遥测、设备列表、后台权限。默认设备地址/图标 override 清理必须仅涉及被恢复元素的字段，并可撤销。

最多 64 项撤销，只记录真实配置编辑。一次 slider 拖动/颜色选择一次记录。必须包括被本设计器修改的真实设备地址和符号偏好，而非只有配置 JSON。模拟编辑/场景/tab/window 不进入历史。其他设置页修改相关图标字段时清空失效历史并提示，不能撤销掉外部新编辑或覆盖不相关偏好。

## 7. 渲染、动效、生命周期

大图使用现有 scene、geometry 与 renderer，菜单栏/Dock继续各自真实渲染。不得把网页 SVG 当作 Swift 实现。几何选择范围足够点击并有键盘/VoiceOver 等价入口；居中继续按可见 ink，数字不随字符宽度偏移。

显式更换中间来源/目标：旧符号轻移左淡出、新符号右入淡入，总时长约 200–240 ms；外环/底部保持静止。拖动数值跟手，不排队回放。连续快速切换只留下最新状态，不产生旧符号残留。颜色/大小直接更新。

Reduce Motion 改为不超过 100 ms 淡化；真实数据更新不反复播放来源切换动画。充电效果复用既有 ChargingEffectClock；关闭/隐藏设计器停止预览动画，不创建常驻计时器。实际菜单栏/Dock不增加新的切换动效。

普通设置和设计器同时打开时，监控可见性采用 owner 集合合并，而不是某个窗口关闭就 `setSettingsVisible(false)`。工具 panel 自身不持有监控 demand。AppActivationPolicy 的临时 regular 请求成对获取/释放，关闭一个窗口不改变其他窗口的正常显示策略。权限初始 publication 不能新建或重新打开用户已经关闭的窗口。

## 8. 验收与非目标

必须通过纯模型、配置持久化、窗口生命周期、source-to-render、menu/Dock parity、12语言、辅助功能测试。用真实开发版手动确认主窗口尺寸、浮动 panel、无权限说明、缩放、键盘和 Reduce Motion。硬件电量读数/实际系统权限变化由用户验收，不能仅凭模拟或代码检查声称通过。

非目标：输入法监控、中间音量新来源、额外设备扫描/连接、全局窗口系统重构、发布、重做已确认的 AirPods 弧线规则。
