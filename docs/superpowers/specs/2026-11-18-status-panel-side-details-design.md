# 状态面板详情并排显示

## 目标与范围

查看详情时，用户可以同时浏览和操作状态面板主界面。电池、Wi-Fi、以太网、输入法，以及系统监控的 CPU、GPU、内存、网络、磁盘详情都使用同一套规则。从菜单栏、Dock 或快捷键打开状态面板时，设置一致生效。原本就在主界面内展开的模块继续在原处展开，各详情页沿用现有内容与操作。

## 备选方案

- **附属面板（已选定）**。主面板保留自己的窗口、锚点、宽度和滚动位置。详情有单独的窗口和高度，主面板可在详情打开时继续操作。两个窗口共用关闭和焦点规则。
- **同一窗口展开两栏**。交给一个窗口处理外部点击和键盘焦点。展开时需要调整现有固定宽度和窗口定位，让主面板仍停在原处，同时分别滚动两栏。

选择附属面板，优先保证主面板位置稳定，并让详情沿用适合自身内容的高度。

## 设置

在「设置 → 状态面板 → 打开行为」提供两个开关。

| 开关 | 说明 |
| --- | --- |
| **并排显示详情** | 默认关闭。开启后，详情显示在状态面板旁边，优先靠右，右侧空间不足时靠左。关闭后，详情在原面板内打开。 |
| **重新打开时恢复详情页** | 开启后，如果上次收起状态面板时详情仍开着，再次打开就按当前模式恢复。关闭后，每次只显示主界面。 |

第二个开关替换「每次打开回到主界面」的文案。UI 反向绑定现有的 `returnsToSummaryOnOpen` 值，沿用同一默认值和导入导出字段。旧开关关闭对应新开关开启，旧开关开启对应新开关关闭。新用户默认开启恢复。并排开关是可迁移的界面偏好，纳入设置导入导出，旧备份若缺少并排字段，导入时保留当前设备的并排设置。实际出现的左右位置始终按当前屏幕计算。

## 打开、切换和关闭

- 打开详情时，主面板保留原位置与滚动状态。并排区域一次显示一页详情。点击另一入口时，在同一位置换页，重复点击当前入口时保持当前页和滚动位置。
- 并排详情页顶部保留标题，将返回按钮改为「关闭详情」。按钮关闭详情并清除待恢复的页面。若通过键盘打开详情，焦点进入详情，关闭后回到触发它的入口，入口已消失时回到主面板可用控件。焦点在两个面板之间切换时，两者都保持打开。
- 按 Esc 时，先给当前控件或确认框处理的机会。并排详情打开时，下一步收起详情并清除待恢复的页面，再按一次收起主面板。面板内跳转（含临时回退）沿用当前 Esc 与返回行为。
- 点击两块面板之外（含两者间的空隙）、切换到其他 App，或再次点击菜单栏／Dock 图标，都按现有入口规则收起整组面板。点设置时沿用「打开设置时保留状态面板」偏好，整组一起保留或关闭。详情内的系统设置、权限与确认流程沿用原来的规则。
- 收起整组时，记住当时仍打开的详情路由，释放详情视图和采集。恢复只在本次 App 运行内有效。重新打开时，先判断是否允许恢复、对应模块和详情是否仍可用，再选择并排或面板内显示。详情因模块隐藏或数据失效而关闭时，清除该路由。
- 当设置窗口与面板同时打开时，切换「并排显示详情」立即按当前模式重新摆放已打开的详情。调整「重新打开时恢复详情页」在下次打开主面板时生效。

## 摆放规则

以主面板当前窗口的位置为锚点，只在主面板所在显示器的可用区域内摆放，计入自动隐藏 Dock 预留空间。

1. 详情沿用目前的 330 pt 宽度。与主面板相隔 8 pt，屏幕边缘至少留 8 pt。完整放得下就开在右边，否则试左边。
2. 两侧都放不下时，当次在主面板内打开同一详情，保留用户的并排设置。主面板位置或屏幕可用区域变化后重新判断。回退期间按主界面正常显示时的位置判断是否能恢复并排，显示方式来回切换时保留当前详情路由和 Wi-Fi 展开状态。
3. 优先与主面板顶部对齐。必要时沿竖直方向移动详情窗，使其完整落在可用区域。超高内容在详情窗内滚动。切换详情或内容高度变化时保持当前侧，屏幕或主面板横向位置变化时才重新选侧。每个窗口使用同一种现有面板背景设置，各自测量高度、管理滚动。

## 实现边界

- 详情路由由现有面板 ViewModel 统一维护，状态面板控制器新增一个可复用的非激活附属 `NSPanel`。共用现有详情内容、权限入口和数据模型。控制器协调两个窗口的焦点、可见区域与整组关闭，关闭详情和收起整组分别走对应的生命周期。
- 明确区分「当前详情路由」和「主界面是否可见」。并排时主界面的采集照常运行，详情只请求当前页的数据。系统监控在同一采集服务合并可见摘要与可见详情的指标，各页专用采集和榜单随详情切换或关闭停止。整组关闭后回到原有后台采集策略。
- 详情窗按需创建，关闭时解除内容与观察。继续支持 macOS 13、现有窗口背景的无障碍回退、全屏 Space 和后台测试入口。逐项确认鼠标、键盘和 VoiceOver 可使用两个窗口，背景测试实例继续遵循仓库的焦点与输入约束。

## 验收

- 单测覆盖右侧、左侧、两侧都放不下、边距临界值、不同坐标原点的显示器、Dock 预留、高内容和屏幕变化后的重新摆放。
- 覆盖全部详情路由、关闭与重新打开的组合、主动关详情后不恢复、入口失效、设置值反向映射及新设置导入导出。验证并排时摘要和详情采集并存，换页和关闭后释放详情专用需求。
- 在授权的真机环境验证菜单栏、Dock 和快捷键入口，覆盖屏幕边缘、左右／底部 Dock、全屏、多屏、焦点切换、Esc、点击外部和打开设置时保留面板。在当前 macOS 与 Ventura 分别记录结果。交付前运行仓库 full 本地验证。
