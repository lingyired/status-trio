# Issue #244：原生极简 DMG 安装页

状态：已在发布 CI 的 macOS runner 上生成真实安装页并截图复核，默认打包布局切回 styled；`plain` 仅保留为显式回退。用户已确认原生极简方向及预览，并要求补充「完成安装后从应用启动台打开」说明。初始基点：`cb62fdd76c854207357cc23ad918165b1c5b300e`（2026-11-03 与 origin/main 一致）；CI 复核基点：`5ff0cff2`（2026-11-05）。

## 目标与视觉

打开 DMG 后，一眼看懂把左侧 Status Trio 拖到右侧 Applications。保留中英文，减少重复信息。

- 画布逻辑尺寸 660 × 420pt，背景 `#F5F5F7`，无卡片、边框、渐变或页脚。
- 标题区位于顶部：中文「将 Status Trio 拖入「应用程序」」21pt medium `#1D1D1F`（top 40）；英文说明 13.5pt `#66666B`（top 76）；第二条中文提示「拖入后即可完成安装，再从应用启动台打开 Status Trio。」13.5pt（top 112）；英文提示 12pt（top 138）。
- Finder 实际可见内容区比 420pt 窗口矮（本机实测约 324pt，含工具栏与路径栏）；所有文字保持在顶部约 160pt 内，底部留白不承载信息，避免被底部栏裁切。
- 图标尺寸 104pt，中心位置 App `(180, 230)`、Applications `(480, 230)`（Finder 的 icon position 为图标中心）；图标标签约在 294pt 处，仍在可见区内。中间为蓝色 `#348DE5` 细线右箭头，垂直中心与图标中心对齐。
- 拖放链接固定命名为 `Applications`，因此标签不随系统语言变化（已决定保持英文，标准做法）。实测 macOS 27 的 `.localized` 只在普通子目录生效，卷根目录不生效，单个 DMG 无法本地化该标签。
- 图标和文件名由 Finder 绘制，背景只画说明与箭头。预览中的图标与文件名仅为位置示意；实际图标、别名标记、名称本地化与标签间距以 Finder 为准。
- 标题下方补充安装完成与从应用启动台打开的提示（见上方标题区）；两者都在可见区内，不依赖窗口底部空间。
- 不重复放「安装 Status Trio」标题，不写版本号或首启绕过说明。
- 背景为固定浅色；不能据此声称深色 Finder 已通过验收。

预览：`issue-244-dmg-installer-preview.png`。

## 资源与坐标

用 Swift/AppKit 生成背景，字体使用系统字体和中文系统回退，不依赖本机字体文件的绝对路径。提供 1x / 2x PNG，分别为 660 × 420 / 1320 × 840 像素；2x 明确标注 144 DPI，作为 create-dmg 的背景输入。坐标和色值集中维护。

相邻的 `@2x` 文件不作为 Finder 自动选图的前提。背景逻辑尺寸、Finder 内容区与外框尺寸的差别均需实际检查；必要时调整窗口高度或背景表示，不能只凭预览认定 Retina 和图标位置已正确。

## 打包接入

使用 create-dmg 1.3.0，发布工作流显式准备该依赖并检查版本；本地缺失时明确报错。暂存目录只放 App，由 `--app-drop-link` 创建唯一的 Applications 链接。

固定卷名、窗口布局、104pt 图标、13pt 标签、隐藏 App 扩展名，使用 `--no-internet-enable`；不写自定义卷图标（不传 `--volicon`），避免用户把卷图标误当成 App 本身，挂载后显示系统通用磁盘图标。保留 UDZO 格式。更正初步检查：1.3.0 的实际源码和完整帮助包含 `--overwrite`；本实现使用独占临时输出目录，不需要覆盖现有产物。

封装 DMG 创建步骤，失败时保留原始错误并清理本次调用拥有的临时文件和挂载。不能按卷名卸载其他镜像，不能静默退回无布局镜像。create-dmg 会调用 Finder AppleScript；本轮设计阶段不启动它，后续执行须按后台 UI 约束评估影响。

create-dmg 会在卷根加入隐藏的 `.background` 辅助目录来承载说明图。Finder 只对当前可见项可靠持久化图标位置，因此必须给它显式坐标，否则在开启「显示隐藏文件」的 Finder 中它会落到顶部默认槽位并盖住说明文字。打包脚本把它定位到窗口外（760/470）并设置 hidden 标记；离线回归断言坐标超出 660pt 宽窗口。不写 `.VolumeIcon.icns`：用户反馈卷图标容易被误认为 App 本身。2026-11-05 的 runner 诊断确认最终镜像只有 `.background` 一项辅助物，且坐标与 hidden 标记写入 `.DS_Store`。

App 公证 → 安装页打包 → DMG 签名与公证 → Sparkle 签名 → manifest 的顺序保持不变。
