# 设置导入与导出

在 **设置 → 通用 → 设置迁移**（英文界面为 **Settings transfer**）中，可以将 Status Trio 的可迁移偏好保存为 JSON，或在预览后导入文件。

## 导出

1. 默认仅导出可迁移偏好与语言选择。
2. 如果需要迁移设备配置，主动开启「包含设备设置」。这个开关同时作用于导出与导入，默认关闭。
3. 选择「导出…」，在系统文件面板中保存 `.json` 文件。

文件采用可读 JSON，包含格式版本、应用版本和导出时间。请将其保存在可信位置；这不是加密备份。

## 导入与确认

1. 如需导入设备配置，先开启「包含设备设置」。
2. 选择「导入…」并选择 JSON 文件，最大为 2 MB。
3. 检查预览中的偏好数量、设备配置数量、来源版本、导出时间与警告。
4. 选择「应用导入」才会变更设置；「取消」不会应用预览内容。取消文件选择同样不会变更设置。

缺少的字段保留当前值；未知字段会跳过并提示；已知字段的非法值按默认值处理，并在确认前提示。损坏文件、不支持的格式版本和超限文件不会导入。警告中的字段名与原因代码保留技术标识，周围的操作说明随应用语言显示。预览只显示前 50 条警告，并显示警告总数；过长的字段名会截断，以免不可信文件造成无界界面开销。未知顶层字段以 `document.foo` 一类路径提示。

导入通过现有设置更新路径应用，不会替换运行中的设置对象。与图标相关的偏好仍同时作用于菜单栏与 Dock，不引入新的菜单栏专属行为。

## 设备匹配与隐私

设备配置使用 SHA-256 身份标记，而不是在普通导出文件中记录原始音频 UID、蓝牙地址或显示器标识。只有与这台 Mac 当前已知设备**精确匹配**的配置才会应用；其余会跳过并显示警告，不会猜测名称相似的设备。

匹配使用应用已经发布的音频输出、音频输入、显示器、蓝牙与 BetterDisplay 设备快照；打开迁移设置不会发起新的扫描或权限请求。尚未出现在快照中的设备可能被跳过；可在设备正常连接、应用已识别后重新导入。不同 Mac 的设备标识可能不同，因此跨机器迁移并不保证匹配。

哈希不是加密，也不等于匿名化：同一身份标记可被关联，部分标识可能被猜测。请谨慎分享含设备配置的文件。设备的信任与授权不会随文件迁移。

## 自动备份与撤销

确认导入后，应用先将当前设置原子保存到本机 Application Support 下的备份位置，再应用变更。如果备份保存失败，导入中止，当前设置保持不变。

成功导入后，界面会显示备份文件的完整路径，可选择文字复制。当前设置根视图存续期间，可以使用「撤销上次导入」恢复导入前的偏好，包括该次备份中暂时断开的设备配置。会话由设置根视图持有；切换到其他设置分类再返回通用，不会丢失撤销、待确认预览或设备设置开关。撤销只针对最近一次成功导入，不是多步历史；设置窗口销毁或应用退出后，不保证仍可使用会话撤销。单独嵌入通用面板时，应注入稳定的外部会话；未注入时使用面板自身生命周期内的本地会话。

备份文件留在磁盘上，可通过导入文件进行恢复。文件恢复仍遵守导入时的设备开关与当前设备精确匹配规则；它与当前会话的完整撤销并不等价。请保留需要的备份，并自行管理不再需要的本地文件。

## 不会迁移的内容

- 登录时启动的系统注册状态。
- 特权 Helper 的安装、批准与系统服务状态，以及依赖 Helper 授权的「控制低电量模式」开关（导入不会应用它，避免造成授权的错觉）。
- 隐私权限、匿名统计同意、设备访问同意与信任状态。
- 全局快捷键。
- 引导完成状态与开发测试预览状态。

这些内容需要在目标机器上手动重新设置或授权。导入文件不能授予系统权限，不能安装 Helper，也不能注册登录项或全局快捷键。

此功能不提供「恢复全部默认设置」，也不备份应用程序、系统设置、设备当前音量/亮度或完整硬件状态。只迁移明确允许的应用偏好与可选设备配置。

## 验证边界

自动化测试覆盖真实本地化资源、错误文案、文件大小边界，以及核心层的预览、备份、应用与撤销行为。静态检查和单元测试不等同于原生文件面板、真实设备、系统授权或 macOS 13 的运行时验证；这些项目需要单独的可见/隔离会话或人工验证。
