# 设置导入与导出

在 **设置 → 通用 → 设置迁移**（英文界面为 **Settings transfer**）中，可以将 Status Trio 的可迁移偏好保存为 JSON，或在预览后导入文件。

## 导出

1. 只导出可迁移偏好与语言选择。
2. 选择「导出…」，在系统文件面板中保存 `.json` 文件。

文件采用明文可读 JSON，包含格式版本、应用版本和导出时间。请将其保存在可信位置；这不是加密备份。

## 导入与确认

1. 选择「导入…」并选择一个 JSON 文件，最大为 2 MB。
2. 检查预览中的偏好数量、来源版本、导出时间与警告。
3. 选择「应用导入」才会变更设置；「取消」不会应用预览内容。取消文件选择同样不会变更设置。

缺少的字段保留当前值；未知字段会跳过并提示；已知字段的非法值按默认值处理，并在确认前提示。损坏文件、不支持的格式版本和超限文件不会导入。警告中的字段名与原因代码保留技术标识，周围的操作说明随应用语言显示。预览只显示前 50 条警告，并显示警告总数；过长的字段名会截断，以免不可信文件造成无界界面开销。未知顶层字段以 `document.foo` 一类路径提示。

导入通过现有设置更新路径应用，不会替换运行中的设置对象。与图标相关的偏好仍同时作用于菜单栏与 Dock，不引入新的菜单栏专属行为。

## 自动备份与撤销

确认导入后，应用先将当前偏好原子保存到本机 Application Support 下的备份位置，再应用变更。如果备份保存失败，导入中止，当前设置保持不变。

成功导入后，界面会显示备份文件的完整路径，可选择文字复制。当前设置根视图存续期间，可以使用「撤销上次导入」恢复导入前的偏好。会话由设置根视图持有；切换到其他设置分类再返回通用，不会丢失撤销或待确认预览。撤销只针对最近一次成功导入，不是多步历史；设置窗口销毁或应用退出后，不保证仍可使用会话撤销。单独嵌入通用面板时，应注入稳定的外部会话；未注入时使用面板自身生命周期内的本地会话。

备份文件留在磁盘上，可通过导入文件进行恢复；它等同一次普通导入，并不提供会话级的多步历史。请保留需要的备份，并自行管理不再需要的本地文件。

## 不会迁移的内容

- 登录时启动的系统注册状态。
- 特权 Helper 的安装、批准与系统服务状态，以及依赖 Helper 授权的「控制低电量模式」开关（导入不会应用它，避免造成授权的错觉）。
- 隐私权限、匿名统计同意、设备访问同意与信任状态。
- 全局快捷键。
- 引导完成状态与开发测试预览状态。
- 设备配置（音频输出/输入、显示器亮度、蓝牙设备等）。设备标识会随机器和外设变化，跨 Mac 迁移没有意义，因此不导出、也不导入。
- 音频优先级自动切换开关及记忆的设备列表。它们依赖本机设备与排序，需在目标机器重新配置。

这些内容需要在目标机器上手动重新设置或授权。导入文件不能授予系统权限，不能安装 Helper，也不能注册登录项或全局快捷键。

此功能不提供「恢复全部默认设置」，也不备份应用程序、系统设置、设备当前音量/亮度或完整硬件状态。只迁移明确允许的应用偏好与语言。
