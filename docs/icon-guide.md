# Optional icon guide

On a fresh installation, the first successful launch opens a standalone guide
window. Selecting a part (or focusing its button with the keyboard) explains the
battery arc, network center, or volume indicator. The volume explanation
follows the current dots/arc setting. The labeled example uses the production
renderer and current icon options, not a separately drawn imitation or live
measurements.

Closing the window, completing the guide, or choosing Customize records the
onboarding as complete and prevents it from opening automatically again.
Existing installations, app updates, restarts, and later launches skip the
automatic window. Settings → App Icon provides an Open Guide button to revisit
it manually. Customize opens the existing Settings window; Audio settings own
volume style.

The guide never requests permissions, changes icon settings, polls, or animates.
It uses standard buttons, localized labels and VoiceOver hints and a selected
trait; all 12 supported languages are included. The manual settings action
remains available even when automatic onboarding was skipped or completed.

This follows Apple's [Onboarding guidance](https://developer.apple.com/design/human-interface-guidelines/onboarding): keep onboarding optional and contextual,
let people learn through interaction, and provide another way to revisit it.
