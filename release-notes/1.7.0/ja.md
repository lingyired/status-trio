# バージョン %VERSION%（ビルド %BUILD%）

### 新機能

- 接続スロットに現在の入力ソースを表示できます。サイズは Wi-Fi アイコンに合わせて変化し、行を選択すると macOS の入力ソース選択画面が開きます。
- 設定可能なグローバルショートカットで、どこからでもステータスパネルを開閉できます。
- ステータスパネルからシステム設定を開かずに Bluetooth をオン／オフできます。
- HUAWEI FreeBuds のノイズキャンセリング、外音取り込み、オフを実際の Bluetooth 接続で切り替えられます。
- メニューバーガイドでアイコンの場所を確認でき、対応するすべての macOS で正しい「メニューバー」設定を開けます。
- Dock に独立した充電アニメーションを表示でき、メニューバーと同じクロックを使用します。

### 改善

- 外付けディスプレイの音量を、現在のデフォルト音声出力に対応するディスプレイへ関連付けます。DDC 読み取りは一般的な 2 種類の要求形式を試します。
- AirPods の音声ルートが後から利用可能になった場合、リスニングモードの操作項目を再検出します。
- オーディオパネルはコンパクトな配置に戻り、マイク音量、読み戻し値、入力デバイスを同期します。
- 充電アニメーションはキャッシュと必要時更新を使用し、安定再生時の CPU 使用量を抑えます。
- Bluetooth 監視、パネル購読、プレビュー、画像キャッシュは、対応する画面が見えなくなるとメモリを解放します。
- 電源ヘルパー、システム分析、ネットワークコマンド、Wi-Fi 認証、テレメトリ、アクセシビリティ、単一インスタンスのライフサイクルを強化しました。

### 注意

- 有効な DDC 読み取りで外付けディスプレイを識別するまで、そのディスプレイには書き込みません。
- パネルを閉じた状態のメモリ使用量は、有効な機能と接続中のハードウェアによって変わります。
