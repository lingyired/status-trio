# 버전 %VERSION%(빌드 %BUILD%)

### 새로운 기능

- 연결 슬롯에 현재 입력 소스를 표시할 수 있습니다. 크기는 Wi-Fi 아이콘에 맞춰지며, 행을 선택하면 macOS 입력 소스 선택기가 열립니다.
- 설정 가능한 전역 단축키로 어디서든 상태 패널을 열거나 닫을 수 있습니다.
- 상태 패널에서 시스템 설정을 열지 않고 Bluetooth를 켜고 끌 수 있습니다.
- HUAWEI FreeBuds의 노이즈 캔슬링, 투명 모드, 끄기를 실제 Bluetooth 연결로 전환할 수 있습니다.
- 메뉴 막대 가이드가 아이콘 위치를 안내하고 지원되는 모든 macOS 버전에서 올바른 메뉴 막대 설정을 엽니다.
- Dock에서 메뉴 막대와 같은 시계를 사용하는 독립 충전 애니메이션을 표시할 수 있습니다.

### 개선 사항

- 외장 디스플레이 볼륨을 현재 기본 오디오 출력의 디스플레이와 연결합니다. DDC 읽기는 두 가지 일반 요청 형식을 모두 시도합니다.
- AirPods 오디오 경로가 나중에 준비되면 듣기 모드 컨트롤을 다시 탐색합니다.
- 오디오 패널이 다시 간결한 레이아웃을 사용하며 마이크 볼륨, 다시 읽은 상태, 입력 장치를 동기화합니다.
- 충전 애니메이션은 캐시와 필요 시 업데이트를 사용하여 안정 재생 중 CPU 사용량을 줄입니다.
- Bluetooth 모니터링, 패널 구독, 미리보기와 이미지 캐시는 해당 UI가 보이지 않을 때 메모리를 해제합니다.
- 전원 도우미, 시스템 분석, 네트워크 명령, Wi-Fi 권한, 텔레메트리, 손쉬운 사용 및 단일 인스턴스 수명 주기를 더 견고하게 만들었습니다.

### 참고

- 유효한 DDC 읽기로 외장 디스플레이를 식별하기 전에는 해당 디스플레이에 데이터를 쓰지 않습니다.
- 패널을 닫았을 때의 메모리 사용량은 활성화한 기능과 연결된 하드웨어에 따라 달라집니다.
