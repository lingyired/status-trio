# Версия %VERSION% (сборка %BUILD%)

### Новые возможности

- В слоте подключения можно показывать текущий источник ввода. Его размер соответствует значку Wi-Fi, а нажатие на строку открывает выбор источника ввода macOS.
- Настраиваемое глобальное сочетание клавиш позволяет открывать и закрывать панель состояния из любого места.
- Панель состояния теперь может включать и выключать Bluetooth без открытия Системных настроек.
- Для HUAWEI FreeBuds можно переключать шумоподавление, прозрачность и выключенный режим через реальное Bluetooth-соединение.
- Руководство по строке меню помогает найти значок и открывает правильный раздел настроек во всех поддерживаемых версиях macOS.
- Dock может показывать независимую анимацию зарядки, используя те же часы, что и строка меню.

### Улучшения

- Громкость внешнего монитора привязывается к монитору текущего устройства вывода звука по умолчанию. При чтении DDC проверяются два распространённых формата запроса.
- Элементы режимов AirPods повторно обнаруживаются, если аудиомаршрут становится доступен позже.
- Аудиопанель снова использует компактную компоновку и синхронизирует громкость микрофона, прочитанное состояние и устройства ввода.
- Анимации зарядки используют кеш и обновляются по требованию, снижая нагрузку на процессор при стабильном воспроизведении.
- Мониторинг Bluetooth, подписки панели, предпросмотры и кеши изображений освобождают память, когда соответствующий интерфейс скрыт.
- Повышена надёжность жизненного цикла помощника питания, системных и сетевых команд, авторизации Wi-Fi, телеметрии, универсального доступа и защиты единственного экземпляра.

### Примечания

- Запись во внешний монитор не выполняется, пока корректное чтение DDC не подтвердит его идентичность.
- Потребление памяти при закрытой панели зависит от включённых функций и подключённого оборудования.
