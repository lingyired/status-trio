# 版本 %VERSION%（組建 %BUILD%）

### 新功能

- 連線槽可顯示目前輸入法/輸入來源，尺寸與 Wi-Fi 圖示一致；點按對應列可開啟 macOS 輸入來源選擇器。
- 新增可設定的全域快速鍵，可從任何位置開啟或關閉狀態面板。
- 狀態面板可直接開關藍牙，無需開啟系統設定。
- 華為 FreeBuds 可透過真實藍牙連線切換降噪、通透與關閉。
- 選單列引導可協助尋找 App 圖示，並在各支援的 macOS 版本開啟正確的「選單列」設定頁。
- Dock 可顯示獨立充電動畫，並與選單列充電動畫共用時鐘。

### 改進

- 外接顯示器音量會對應目前預設音訊輸出所屬的顯示器；DDC 讀取會探測兩種常見請求格式，不再假定只有一種。
- AirPods 音訊路由稍後就緒時，會重新探索聆聽模式控制項。
- 音訊面板恢復緊湊版面，並保持麥克風音量、讀回狀態與輸入裝置同步。
- 充電動畫使用快取與按需排程，降低穩定播放時的 CPU 使用量。
- 藍牙監控、面板訂閱、預覽與圖片快取會在對應介面不可見後釋放記憶體。
- 電源 Helper、系統分析程序、網路命令、Wi-Fi 授權、遙測、輔助功能與單一實例生命週期更穩健。

### 說明

- 在有效 DDC 讀取確認顯示器身分前，App 不會向顯示器寫入資料。
- 關閉面板後的實際記憶體取決於啟用的功能與目前連接的硬體。
