# 版本 %VERSION%（构建 %BUILD%）

### 新功能

- 连接槽可显示当前输入法/输入源，尺寸与 Wi-Fi 图标一致；点击对应行可打开 macOS 输入源选择器。
- 新增可配置的全局快捷键，可从任意位置打开或关闭状态面板。
- 状态面板可直接开关蓝牙，无需打开系统设置。
- 华为 FreeBuds 可通过真实蓝牙连接切换降噪、通透和关闭。
- 菜单栏引导可帮助定位应用图标，并在各受支持 macOS 版本打开正确的“菜单栏”设置页。
- Dock 可显示独立充电动画，并与菜单栏充电动画共享时钟。

### 改进

- 外接显示器音量会匹配当前默认音频输出对应的显示器；DDC 读取会探测两种常见请求格式，不再假定只有一种。
- AirPods 音频路由稍后就绪时，会重新发现聆听模式控件。
- 音频面板恢复紧凑布局，并保持麦克风音量、读回状态和输入设备同步。
- 充电动画使用缓存和按需调度，降低稳定播放时的 CPU 占用。
- 蓝牙监控、面板订阅、预览和图片缓存会在对应界面不可见后释放内存。
- 电源 Helper、系统分析进程、网络命令、Wi-Fi 授权、遥测、辅助功能和单实例生命周期更稳健。

### 说明

- 在有效 DDC 读取确认显示器身份前，应用不会向显示器写入数据。
- 关闭面板后的实际内存取决于启用的功能和当前连接的硬件。
