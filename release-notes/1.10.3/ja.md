# バージョン %VERSION%（ビルド %BUILD%）

### ステータスパネル

- パネルの文字を太字にする設定を追加しました。選択中の入出力デバイス名にも適用されます（#364）。
- 音量・明るさ・マイクのスライダーに、自動・プリセット・カスタムの色を設定できます。色はすぐに反映され、100% で操作を終えると塗りつぶしが右端まで届きます（#359）。
- スクロールバーが macOS の表示設定に従うようになりました。Bluetooth の見出し色とオーディオデバイス一覧の間隔も調整しました（#360）。

### アイコンとリング

- カスタムリングの充電インジケーターが「バッテリー → 上部マーカー」の設定に従います。左右のデュアルリングで稲妻やプラグが表示されない問題を修正し、バッテリーとアイコンの両方のページで同じ設定を変更できます（#361、#362）。

### システムモニター

- SSD 容量リングの色を変更できます。ネットワーク・ファン・ディスクの詳細画面も各指標の色に従います。
- App メモリと使用済みメモリの計算をアクティビティモニタの定義に合わせました（#363）。
- M5・M6 シリーズの CPU/GPU 温度に対応し、より多くの Intel CPU コアの温度を読み取れるようにしました（#358）。
- GPU やネットワークの使用量が多いアプリの一覧が早く表示され、詳細画面を開き直すと前回の順位が先に表示されます（#365）。
