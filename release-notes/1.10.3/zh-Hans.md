# 版本 %VERSION%（构建 %BUILD%）

### 状态面板

- 新增「加粗面板文字」开关，选中的输入和输出设备名称也跟随设置（#364）。
- 音量、亮度和麦克风滑条支持自动配色、预设和自选颜色。改色立即生效，松开后 100% 的填充会到达滑条右端（#359）。
- 滚动条跟随 macOS 的「显示滚动条」设置，蓝牙标题颜色和音频设备列表间距也做了调整（#360）。

### 图标与圆环

- 自定义圆环的充电标志跟随「电池 → 顶部标识」，修复左右双环丢失闪电或插头图标的问题。电池页和图标页共用这组设置（#361、#362）。

### 系统监控

- SSD 容量环可以自选颜色，网络、风扇和磁盘详情跟随指标配色。
- 修正应用内存和已用内存的计算，使其与活动监视器的口径一致（#363）。
- 补充 M5、M6 系列的 CPU 和 GPU 温度读取，并扩大 Intel CPU 核心温度的读取范围（#358）。
- GPU 和网络的高占用应用列表更快取得首批数据，重新打开详情时会先显示上次的排行（#365）。
