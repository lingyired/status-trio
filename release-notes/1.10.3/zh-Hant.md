# 版本 %VERSION%（組建 %BUILD%）

### 狀態面板

- 新增「加粗面板文字」開關，選取的輸入和輸出裝置名稱也會跟隨設定（#364）。
- 音量、亮度和麥克風滑桿支援自動配色、預設和自訂顏色。改色立即生效，放開後 100% 的填色會到達滑桿右端（#359）。
- 捲軸跟隨 macOS 的「顯示捲軸」設定，也調整了藍牙標題顏色與音訊裝置清單間距（#360）。

### 圖示與圓環

- 自訂圓環的充電標誌跟隨「電池 → 頂部標識」，修正左右雙環漏顯閃電或插頭圖示的問題。電池和圖示頁共用這組設定（#361、#362）。

### 系統監控

- SSD 容量環可自訂顏色，網路、風扇和磁碟詳情跟隨指標配色。
- 修正應用程式記憶體和已使用記憶體的計算，使其與「活動監視器」定義一致（#363）。
- 補充 M5 和 M6 系列的 CPU 和 GPU 溫度讀取，並擴大 Intel CPU 核心溫度的讀取範圍（#358）。
- GPU 和網路的高用量 App 清單更快取得首批資料，重新開啟詳情時會先顯示上次的排名（#365）。
