# Версия %VERSION% (сборка %BUILD%)

### Новые возможности

- Добавлен необязательный раздел «Рядом», который показывает уровень заряда близлежащих BLE-устройств со стандартной службой батареи.
- Добавлена настройка действия панели батареи: можно открыть настройки батареи, AlDente, BatFi, выбранное приложение или собственный URL. Если цель недоступна, откроются настройки батареи.

### Улучшения и исправления

- Поиск устройств поблизости по умолчанию выключен, выполняется только при открытой панели состояния Bluetooth и не меняет сведения о сопряжённых устройствах. Поддержка зависит от устройства; уровень заряда iPhone и iPad не гарантируется.
