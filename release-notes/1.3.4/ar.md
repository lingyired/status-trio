# الإصدار %VERSION% (البنية %BUILD%)

### ميزات جديدة

- أُضيف قسم «القريب» الاختياري لقراءة مستويات بطارية أجهزة BLE القريبة التي توفر خدمة البطارية القياسية.
- أُضيف إعداد لإجراء لوحة البطارية لفتح إعدادات البطارية أو AlDente أو BatFi أو تطبيق محدد أو عنوان URL مخصّص. تعود الأهداف غير المتاحة إلى إعدادات البطارية.

### تحسينات وإصلاحات

- يكون البحث عن الأجهزة القريبة متوقفًا افتراضيًا، ولا يعمل إلا أثناء ظهور لوحة Bluetooth، ولا يغيّر معلومات الأجهزة المقترنة. يختلف الدعم حسب الجهاز، ولا نضمن قراءة مستويات بطارية iPhone أو iPad.
