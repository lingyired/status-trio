# バージョン %VERSION%（ビルド %BUILD%）

### 新機能

- 標準のバッテリーサービスを提供する近くの BLE デバイスのバッテリー残量を読み取る、任意で有効にできる「近く」セクションを追加しました。
- バッテリーパネルで開く項目を選べる設定を追加しました。バッテリー設定、AlDente、BatFi、選択したアプリ、またはカスタム URL を開けます。利用できない場合はバッテリー設定を開きます。

### 改善と修正

- 近くのデバイスのスキャンはデフォルトでオフになり、Bluetooth ステータスパネルの表示中だけ実行されます。ペアリング済みデバイスの情報は変更しません。対応状況はデバイスによって異なり、iPhone や iPad のバッテリー残量を取得できるとは限りません。
