# Versión %VERSION% (compilación %BUILD%)

### Novedades

- Se añadió una sección opcional «Cercanos» que lee el nivel de batería de dispositivos BLE próximos que ofrecen el servicio estándar de batería.
- Se añadió una opción para la acción del panel de batería: abrir Ajustes de batería, AlDente, BatFi, una app seleccionada o una URL personalizada. Si el destino no está disponible, se abren los ajustes de batería.

### Mejoras y correcciones

- La búsqueda de dispositivos cercanos está desactivada de forma predeterminada, solo se ejecuta mientras está visible el panel de estado de Bluetooth y no modifica la información de los dispositivos enlazados. La compatibilidad depende del dispositivo; no se garantiza la lectura de batería de iPhone o iPad.
