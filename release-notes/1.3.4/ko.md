# 버전 %VERSION%(빌드 %BUILD%)

### 새로운 기능

- 표준 배터리 서비스를 제공하는 주변 BLE 기기의 배터리 잔량을 읽는 선택형 근처 섹션을 추가했습니다.
- 배터리 패널 동작 설정을 추가해 배터리 설정, AlDente, BatFi, 선택한 앱 또는 사용자 지정 URL을 열 수 있습니다. 대상을 사용할 수 없으면 배터리 설정이 대신 열립니다.

### 개선 사항 및 수정

- 주변 기기 검색은 기본적으로 꺼져 있으며 Bluetooth 상태 패널이 표시될 때만 실행되고 페어링된 기기 정보는 변경하지 않습니다. 기기마다 지원이 다르며 iPhone 및 iPad 배터리 잔량은 보장되지 않습니다.
