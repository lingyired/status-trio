# 버전 %VERSION% (빌드 %BUILD%)

### 패널 및 Bluetooth 오디오

- AirPods에서 이제 스테레오 공간화와 대화 인식을 지원합니다.
- Redmi / Xiaomi 이어폰의 리스닝 모드 전환을 추가했습니다.
- 이어폰을 케이스에 다시 넣은 뒤 약 2분 동안 "연결됨"으로 표시되던 문제를 수정했습니다.
- 상태 아이콘을 한 번 클릭하면 패널이 닫히지 않고 새로고침되던 문제를 수정했습니다(일반 모드, 메뉴 막대 전용 모드, 아이콘 가장자리 클릭 포함) (#224).
- 스크롤 휠 볼륨 조절이 더 부드러워졌습니다. 이벤트마다 즉시 갱신하고 슬라이더에 짧은 이징을 적용하며, 한 단계를 1/16으로 하여 시스템 볼륨 키에 가깝게 맞췄습니다.

### 배터리 및 전원

- 상태 패널과 세부 정보에 남은 사용 시간을 표시하고, 세부 정보에는 배터리 온도도 표시합니다 (#298).
- "최대 용량"은 시스템 상태 백분율을 사용해 macOS 표시와 일치시켰으며 (#317), 상태를 읽을 수 없으면 시스템 정보로 대체합니다.
- 전력 내역은 USB 출력을 포트별로 나누고 각 액세서리 이름을 표시합니다. 충전 포트가 300W 한도에 도달하면 USB 출력 전체가 사라지던 문제와 일부 모델에서 내장 디스플레이 전력이 표시되지 않던 문제를 수정했습니다.
- 배터리가 없는 Mac은 가득 찬 링을 표시하고 상단 표시기를 번개/플러그로 전환할 수 있습니다 (#310). 가득 찬 링은 전원 연결 시에만 적용됩니다 (#318).
- "지금 완전 충전"이 시스템 기본 동작과 일치하며, 불필요한 "충전 한도 복원" UI를 제거했습니다.
- 디스플레이가 잠들면 전력 샘플링과 주변 Bluetooth 스캔을 일시 중지하고 깨어나면 재개하여 에너지를 절약합니다 (#300).
- 전원 모드 세그먼트 컨트롤이 Liquid Glass에 맞게 반투명 배경을 사용합니다.

### 아이콘 및 모양

- "충전 및 연결 시 흑백 아이콘 사용" 옵션을 추가했습니다 (#309).
- 배터리 상단 표시기를 사용 상태(배터리 / 충전 등)별로 따로 설정할 수 있습니다 (#315).
- 메뉴 막대 상단 링 부품이 어긋나고 흔들리던 문제를 수정했습니다 (#30).
- Dock 충전 애니메이션 아이콘이 1x 디스플레이에서 절반 크기로 줄어들던 문제를 수정했습니다 (#303).

### 디스플레이 및 밝기

- 밝기 설정에서 BetterDisplay 디스플레이를 수동으로 선택할 수 있고, 밝기를 읽을 수 없을 때 수동 전환을 안내합니다 (#313).
- 외장 디스플레이의 식별이 모호할 때 밝기를 조절할 수 없던 문제를 수정했습니다(유일한 외장 디스플레이로 대체).

### 네트워크 및 입력 소스

- "Wi-Fi 끄기 전 확인" 스위치를 추가했습니다 (#305).
- 병음 입력 소스 표시기가 간체/번체 병음을 구분합니다. 간/번 마커는 선택 사항이 되었고 "中"도 표시할 수 있습니다.

### 기타

- 볼륨 읽기에 실패할 때 출력 장치 목록이 사라지던 문제를 수정했습니다 (#296).
