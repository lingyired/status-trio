# バージョン %VERSION%（ビルド %BUILD%）

### バッテリー

- バッテリーの電力の流れを追加し、充電器の入力電力、バッテリーへの充電電力、システム電力の推定値を表示できるようにしました。充電器入力は初期状態でオフ、ほかの2項目はオンです。
- 最近のサンプルから最大5個のアプリを表示する、CPU エネルギー影響のオプションリストを追加しました。エネルギーカウンターを利用できない場合は CPU アクティビティに切り替え、10〜60秒のサンプリング間隔に対応します。
- Apple シリコン搭載の対応 Mac と macOS 26.4 以降では、「今すぐ満充電」と「今すぐ満充電をキャンセル」を利用でき、機能が使用可能な場合は初期状態で有効です。

### 外部ディスプレイ

- macOS が直接音量を制御できない外部ディスプレイや音声出力向けに、BetterDisplay を使った音量制御方式を追加しました。ディスプレイの自動または手動関連付けに対応し、接続状態とエラー状態を表示します。
- 書き込み可能なネイティブ音量を優先し、Standard/DDC モードへいつでも戻せます。BetterDisplay が利用できない場合、Status Trio は BetterDisplay を起動したり設定を変更したりしません。

### 安定性とインターフェース

- Wi-Fi イベント処理を改善し、高頻度の CoreWLAN コールバックをまとめ、異常状態での復旧頻度を制限しました。イベントストームによって CPU とメモリの負荷が増幅されるリスクを抑えます。
- ステータスパネルを再度開いたときに、ルートページへ戻らず現在の詳細ページを保持するようになりました。
- バッテリー詳細のレイアウト、詳細ページの移動、歯車のクリック領域、リアルタイム電力の更新を改善しました。
- メニューバーのカラー層とテンプレート画像の合成を改善しました。フォーカスのないディスプレイは正しく暗く表示され、Space 切り替え時のシステムによる再着色も維持されます。

### 重要な注意事項

- 「今すぐ満充電」は非公開の PowerUI インターフェースを使用し、Apple シリコン搭載 Mac と macOS 26.4 以降でのみ利用できます。macOS のバージョン間で動作を保証するものではありません。
- 充電完了後や電源アダプタの再接続後も、充電上限が 100% のまま残る場合があります。Status Trio は自動復元しません。「今すぐ満充電をキャンセル」を使うか、システム設定で上限を復元してください。
- CPU エネルギー影響リストはアプリ全体のエネルギー消費量ではなく、macOS の「エネルギー使用量の多い項目」リストのコピーでもありません。
- BetterDisplay を使った音量制御には BetterDisplay の実行が必要です。ディスプレイ音量と DDC の動作は、引き続きハードウェアと接続方式によって異なります。
