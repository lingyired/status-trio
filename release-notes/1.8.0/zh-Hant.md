# 版本 %VERSION%（組建 %BUILD%）

### 電池

- 新增電池功率流向：顯示充電器輸入、充入電池和系統供電的估算功率。充電器輸入預設關閉，另外兩項預設開啟。
- 新增可選的 CPU 能耗影響列表，依最近取樣值顯示最多五個應用程式；能耗計數不可用時改用 CPU 活躍度，並支援 10–60 秒取樣間隔。
- 在 Apple 晶片且執行 macOS 26.4 或更新版本的相容裝置上，支援「立即充滿電」和「取消立即充滿」。相容時預設開啟。

### 外接顯示器

- 新增 BetterDisplay 音量控制方式：當 macOS 無法直接控制外接顯示器或音訊輸出的音量時，可自動配對或手動關聯顯示器，並顯示運作及錯誤狀態。
- 原生可寫音量優先，Standard/DDC 模式仍可隨時恢復；BetterDisplay 無法使用時不會自動啟動或修改其設定。

### 穩定性與介面

- 改進 Wi-Fi 事件處理：合併高頻 CoreWLAN 回呼並限制異常狀態下的恢復頻率，降低事件風暴放大 CPU 和記憶體壓力的風險。
- 重新開啟面板時保留目前詳情頁面，不再直接返回首頁。
- 改善電池詳情版面、詳情頁跳轉、齒輪區域點擊範圍以及即時功率重新整理。
- 改進選單列彩色圖層與模板圖示的合成；未聚焦顯示器可正確呈現變暗效果，並保留切換空間時由系統重新著色的能力。

### 注意事項

- 「立即充滿電」依賴私有 PowerUI 介面，僅支援 Apple 晶片及 macOS 26.4 或更新版本，不提供跨 macOS 版本保證。
- 充電完成或重新插拔電源後，充電上限可能仍保持 100%；Status Trio 不會自動恢復，需要使用「取消立即充滿」或在系統設定中手動恢復。
- CPU 能耗影響不是應用程式全部能耗，也不是 macOS「使用大量能耗」列表的副本。
- BetterDisplay 音量控制需要 BetterDisplay 正常執行；顯示器音量和 DDC 行為仍取決於硬體與連線方式。
