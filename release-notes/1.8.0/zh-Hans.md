# 版本 %VERSION%（构建 %BUILD%）

### 电池

- 新增电池功率流向：显示充电器输入、充入电池和系统供电的估算功率。充电器输入默认关闭，另外两项默认开启。
- 新增可选的 CPU 能耗影响列表，按最近采样值显示最多五个应用；能耗计数不可用时回退到 CPU 活跃度，支持 10–60 秒采样间隔。
- 在 Apple 芯片且运行 macOS 26.4 或更高版本的兼容设备上，支持“立即充满电”和“取消立即充满”。兼容时默认开启。

### 外接显示器

- 新增 BetterDisplay 音量控制方式：当 macOS 无法直接控制外接显示器或音频输出的音量时，可自动匹配或手动关联显示器，并显示运行及错误状态。
- 原生可写音量优先，Standard/DDC 模式仍可随时恢复；BetterDisplay 不可用时不会自动启动或修改其设置。

### 稳定性与界面

- 改进 Wi-Fi 事件处理：合并高频 CoreWLAN 回调并限制异常状态下的恢复频率，降低事件风暴放大 CPU 和内存压力的风险。
- 重新打开面板时保留当前详情页面，不再直接返回首页。
- 改善电池详情布局、详情页跳转、齿轮区域点击范围以及实时功率刷新。
- 改进菜单栏彩色图层与模板图标的合成；未聚焦显示器可正确呈现变暗效果，并保留切换空间时由系统重新着色的能力。

### 注意事项

- “立即充满电”依赖私有 PowerUI 接口，仅支持 Apple 芯片及 macOS 26.4 或更高版本，不提供跨 macOS 版本保证。
- 充电完成或拔插电源后，充电上限可能仍保持 100%；Status Trio 不会自动恢复，需要使用“取消立即充满”或在系统设置中手动恢复。
- CPU 能耗影响不是应用全部能耗，也不是 macOS“使用大量能耗”列表的副本。
- BetterDisplay 音量控制需要 BetterDisplay 正常运行；显示器音量和 DDC 行为仍取决于硬件与连接方式。
