# 버전 %VERSION%(빌드 %BUILD%)

### 배터리

- 배터리 전력 흐름을 추가하여 충전기 입력, 배터리로 유입되는 전력, 시스템 전력의 예상값을 표시합니다. 충전기 입력은 기본적으로 꺼져 있고 나머지 두 값은 기본적으로 켜져 있습니다.
- 최근 샘플을 기준으로 최대 5개 앱을 표시하는 선택적 CPU 에너지 영향 목록을 추가했습니다. 에너지 카운터를 사용할 수 없으면 CPU 활동으로 전환하며 10–60초 샘플링 간격을 지원합니다.
- Apple 실리콘 Mac 및 macOS 26.4 이상의 지원 기기에서는 ‘지금 완전 충전’과 ‘완전 충전 취소’를 사용할 수 있으며, 기능이 지원되면 기본적으로 켜져 있습니다.

### 외부 디스플레이

- macOS가 볼륨을 직접 제어할 수 없는 외부 디스플레이 또는 오디오 출력을 위해 BetterDisplay 볼륨 제어 방식을 추가했습니다. 디스플레이 자동 또는 수동 연결을 지원하고 연결 및 오류 상태를 표시합니다.
- 쓰기 가능한 네이티브 볼륨을 우선하며 Standard/DDC 모드로 언제든지 돌아갈 수 있습니다. BetterDisplay를 사용할 수 없을 때 Status Trio는 BetterDisplay를 실행하거나 설정을 변경하지 않습니다.

### 안정성 및 인터페이스

- 고빈도 CoreWLAN 콜백을 병합하고 비정상 상태에서 복구 빈도를 제한하도록 Wi-Fi 이벤트 처리를 개선하여 이벤트 폭주가 CPU 및 메모리 부담을 증폭시키는 위험을 줄였습니다.
- 상태 패널을 다시 열 때 루트 페이지로 돌아가지 않고 현재 세부 정보 페이지를 유지합니다.
- 배터리 세부 정보 레이아웃, 세부 페이지 이동, 톱니바퀴 클릭 영역 및 실시간 전력 새로 고침을 개선했습니다.
- 메뉴 막대의 컬러 레이어와 템플릿 이미지 합성을 개선했습니다. 포커스가 없는 디스플레이는 올바르게 어둡게 표시되며 Space를 전환할 때 시스템의 재색상 처리도 유지됩니다.

### 중요 사항

- ‘지금 완전 충전’은 비공개 PowerUI 인터페이스를 사용하며 Apple 실리콘 Mac 및 macOS 26.4 이상에서만 사용할 수 있습니다. macOS 버전 간 동작은 보장되지 않습니다.
- 충전이 완료되거나 전원 어댑터를 다시 연결한 뒤에도 충전 한도가 100%로 남을 수 있습니다. Status Trio는 이를 자동으로 복원하지 않습니다. ‘완전 충전 취소’를 사용하거나 시스템 설정에서 한도를 복원하십시오.
- CPU 에너지 영향 목록은 앱의 전체 에너지 사용량이 아니며 macOS의 ‘에너지 사용량이 많은 항목’ 목록을 복사한 것도 아닙니다.
- BetterDisplay 볼륨 제어를 사용하려면 BetterDisplay가 실행 중이어야 합니다. 디스플레이 볼륨과 DDC 동작은 계속 하드웨어 및 연결 방식에 따라 달라집니다.
