# Версия %VERSION% (сборка %BUILD%)

## Исправления

- Исправлено ложное сообщение «не удаётся прочитать состояние "не засыпать при закрытой крышке"» (код DS-R4) на Mac, где эта функция ни разу не включалась. macOS показывает параметр только после первого использования, поэтому теперь приложение считает отсутствующее значение выключенным, а не ошибкой чтения.
- Переключатель «не засыпать при закрытой крышке» теперь показывает правильное начальное состояние и срабатывает с первого нажатия на таких Mac, без ручного запуска `sudo pmset -a disablesleep`.
