# 버전 %VERSION% (빌드 %BUILD%)

### 메뉴 막대

- 상태 항목의 오른쪽 클릭 빠른 동작을 설정할 수 있습니다: 컨텍스트 메뉴 표시, 저전력 모드 전환, 완전 충전/취소, 음소거, Wi‑Fi 켜기/끄기, 새로 고침, 또는 Wi‑Fi/Bluetooth/배터리/사운드 설정 직접 열기 (#209).

### 패널

- Dock 아이콘에서 패널을 열 때 위치가 잘못 표시되는 문제를 수정했습니다 (#229).
- 패널이 화면을 넘어가는 문제를 수정했습니다 (#237).
- 패널 배경 선택 가능: 리퀴드 글래스, 단색, 클래식 소재 (#233).
- 상태 패널을 열 때의 끊김을 개선했습니다 (#232):
  - 다시 열면 Bluetooth 행이 마지막으로 확인된 장치를 즉시 표시하고 배터리 잔량은 백그라운드에서 갱신됩니다;
  - 첫 장치를 읽기 전까지 Bluetooth 부제목을 숨기고, 잔량이 들어올 때까지 행을 고정합니다;
  - 전력 정보 막대는 첫 읽기 전까지 스켈레톤으로 자리를 확보해 열 때의 깜빡임을 없애고, 표시 애니메이션을 짧게 했습니다.
- 전력 정보 막대 UI를 다듬었습니다 (#230, #238): 방전 방향을 표시하고, 배터리 사용 시 "어댑터 없음"을 표시하며, 방전 소스를 주황색으로 표시하고, 충전 입력 카드는 적응형 실버 표면을 사용합니다.
- 투명도 감소 시 채움색을 실제 외관에 맞춰 해석합니다 (#234).
- 패널이 열린 상태에서 상태 항목을 한 번 클릭하면 즉시 적용됩니다 (#224).

- "지금 완전 충전" 후 취소할 때의 오류를 수정했습니다 (#243).
