# 版本 %VERSION%（构建 %BUILD%）

### 新功能

- 输入法图标：中间连接图标可显示当前输入法或输入源，点击对应行可打开 macOS 输入源选择器；可在 App 设置 → 网络中修改。
- 全局快捷键：支持自定义快捷键，从任意位置打开或关闭状态面板。
- 蓝牙开关：可直接在状态面板中开启或关闭蓝牙，无需进入系统设置。
- 华为 FreeBuds 聆听模式：支持通过蓝牙连接切换降噪、通透和关闭模式。
- Dock 充电动画：Dock 可独立显示充电动画，并与菜单栏动画保持同步。

### 体验改进与修复

- 输入法图标显示：修复微信输入法等使用 PDF 图标的输入源在菜单栏和 Dock 中不显示或显示过小的问题。
- 外接显示器音量：根据当前默认音频输出匹配对应显示器，改善 DDC 通信兼容性。
- 音频面板：恢复紧凑布局，改善麦克风音量滑块与设备状态同步；修复部分 AirPods 音频路由就绪后仍不显示聆听模式控件的问题。
- 面板控件对齐：统一电池、网络、蓝牙和音频等区域的按钮与控件布局。
- 菜单栏定位引导：改善图标定位和系统设置跳转，修复引导高亮反复闪烁的问题。
- 应用唤起行为：修复通过 Dock、Finder 或 Spotlight 唤起应用时，状态面板与设置窗口的打开行为。

### 性能与稳定性

- 优化充电动画的缓存与调度，降低持续播放时的 CPU 占用。
- 在相关界面关闭或不可见后，释放蓝牙监控、面板订阅、预览和图片缓存占用的内存。
- 改善蓝牙权限处理、电源 Helper、系统命令超时和应用生命周期管理，提升长期运行的稳定性。
