# 버전 %VERSION%(빌드 %BUILD%)

### 새로운 기능

- 입력 소스 아이콘: 중앙 연결 아이콘에 현재 입력 방식 또는 입력 소스를 표시할 수 있습니다. 해당 행을 선택하면 macOS 입력 소스 선택기가 열립니다. 앱 설정 > 네트워크에서 변경할 수 있습니다.
- 전역 단축키: 어디서든 상태 패널을 열거나 닫는 사용자 지정 단축키를 설정할 수 있습니다.
- Bluetooth 스위치: 시스템 설정을 열지 않고 상태 패널에서 직접 Bluetooth를 켜거나 끌 수 있습니다.
- HUAWEI FreeBuds 청취 모드: Bluetooth 연결을 통해 노이즈 캔슬링, 주변 소리 듣기, 꺼짐 모드를 전환할 수 있습니다.
- Dock 충전 애니메이션: Dock에서 독립적인 충전 애니메이션을 표시할 수 있으며 메뉴 막대 애니메이션과 동기화됩니다.

### 사용성 개선 및 수정

- 입력 소스 아이콘 표시: WeType처럼 PDF 아이콘을 사용하는 입력 소스에서 메뉴 막대와 Dock의 아이콘이 표시되지 않거나 너무 작게 표시되는 문제를 수정했습니다.
- 외장 디스플레이 볼륨: 현재 기본 오디오 출력에 연결된 디스플레이에 볼륨 컨트롤을 맞추고 DDC 호환성을 개선했습니다.
- 오디오 패널: 간결한 레이아웃을 복원하고 마이크 볼륨 슬라이더와 기기 상태 간 동기화를 개선했습니다. 일부 AirPods에서 오디오 경로가 준비된 후에도 청취 모드 컨트롤이 표시되지 않는 문제를 수정했습니다.
- 패널 컨트롤 정렬: 배터리, 네트워크, Bluetooth, 오디오 섹션의 버튼과 컨트롤 배치를 통일했습니다.
- 메뉴 막대 아이콘 가이드: 아이콘 위치와 시스템 설정으로의 이동을 개선하고, 가이드 하이라이트가 반복해서 깜박이는 문제를 수정했습니다.
- 앱 활성화 동작: Dock, Finder 또는 Spotlight를 통해 앱을 활성화할 때 상태 패널과 설정 윈도우가 열리는 동작을 수정했습니다.

### 성능 및 안정성

- 충전 애니메이션의 캐싱과 스케줄링을 최적화하여 연속 재생 중 CPU 사용량을 줄였습니다.
- 해당 인터페이스를 닫거나 더 이상 표시하지 않을 때 Bluetooth 모니터링, 패널 구독, 미리보기 및 이미지 캐시가 사용하는 메모리를 해제합니다.
- Bluetooth 권한 처리, 전원 도우미, 시스템 명령 시간 초과 및 앱 수명 주기 관리를 개선하여 장기 실행 안정성을 높였습니다.
