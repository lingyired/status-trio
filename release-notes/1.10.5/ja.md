# バージョン %VERSION%（ビルド %BUILD%）

## 新機能

- 下部インジケーターに「メモリプレッシャー」を追加し、現在のメモリ使用状況をひと目で確認できるようになりました。
- ディスク詳細ですべてのマウント済みボリューム（内蔵・外付け）を一覧表示し、各ボリュームの読み書き速度を個別に表示します。上部のパーセントは外付け SSD を含めるか選択できます。
- ハードウェア監視の4つのリングは進捗を左右に分割表示でき、上部のパーセントがリングを隠さなくなりました。
- ハードウェア詳細ページに「アクティビティモニタを開く」ボタンを追加し、リソースを消費しているものをすぐ確認できます。
- 高使用率／高消費電力リストで行を固定して強制終了（アプリの子プロセスを含む）できるようになりました。カードには更新カウントダウンが表示され、終了後はすぐに一覧から消えます。

## 修正

- M3 Air の GPU 温度が読み取れない問題を修正し、同じ領域が二重に計上されないようにしました。
- M5 / M6 の CPU 温度の計算ロジックを最適化しました。
- A18 Pro の識別に対応しました。認識できないチップは誤った温度ではなく「利用不可」と表示します。
- 実際の測定値がないのに 0.00 W のディスプレイ消費電力を表示する一部モデルの問題を修正しました。
- 実際の測定値がない場合は推定値を出さず、ディスプレイ消費電力を非表示にしました。画面オフや蓋を閉じた状態で古い値が残らなくなりました。
- 0 W のディスプレイと USB の消費電力を実際の電力として表示しないようにしました。
- コールドスタート時に蓋設定の初回読み取りが失敗する問題を修正し、自動で再試行するようにしました。
- アプリがバックグラウンドサービスより先にタイムアウトして誤報する問題を修正しました。失敗時のメッセージにエラーコードを付けて調査しやすくしました。
- 音声デバイスが利用できない場合は音量スライダーを隠し、「利用可能なデバイスがありません」と表示します。
- 英語の一部文言と長いテキストを調整し、切れないようにしました。
