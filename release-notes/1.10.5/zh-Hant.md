# 版本 %VERSION%（建置 %BUILD%）

## 感測器與溫度

- M3 Air（Mac15,12）GPU 溫度恢復：將無法讀取的 Tf 感測器換成已驗證可讀的 Tg 感測器，並依六對分組，避免同一個實體區域重複計數。
- M5、M6 的 CPU 溫度現在會合併屬於同一核心的多個探針；多個探針不再被當成多個核心，也不會抬高平均值。
- 新增 A18 Pro 辨識。未知晶片不再借用其他世代的溫度 Key；讀不到時顯示不可用，而不是看似合理但錯誤的數字。

## 顯示器功耗

- 修正 Issue #374：沒有 PDBR、PBLR 又固定為 0 的 M3 Air，不再顯示 0.00 W 的顯示器分支。
- 沒有可用的實測背光軌道時，直接隱藏顯示器分支，不發布估算值。
- 0 W 的顯示器與 USB 分支不再繪製成真實功耗。

## 監控與效能

- 感測器能力只探測一次並快取；不存在的 Key 會退避，不再每次重新整理都重試。
- 沒有新增常駐計時器、Helper 或特權存取；關閉相關面板後，溫度與背光擷取仍會停止。
