# 版本 %VERSION%（建置 %BUILD%）

## 新增功能

- 底部指示器新增「記憶體壓力」選項，可直觀查看目前記憶體使用情況。
- 磁碟詳情會列出所有已掛載的卷（內建與外接），並分別顯示各卷的讀寫速度；頂部百分比可選擇是否計入外接 SSD。
- 硬體監控四個圓環支援進度左右平分顯示，頂部百分比不再遮擋進度。
- 硬體詳情頁新增「打開活動監視器」按鈕，可快速查看資源佔用來源。
- 高佔用 / 高能耗列表支援鎖定單列後強制退出（含應用程式子程序），卡片帶更新倒數，退出後該項自動移除。

## 問題修正

- 修正 M3 Air GPU 溫度無法讀取的問題，並避免同一區域的溫度被重複計算。
- M5 / M6 的 CPU 溫度計算邏輯最佳化。
- 新增 A18 Pro 晶片識別；無法識別的晶片改為顯示不可用，不再給出錯誤溫度。
- 修正部分機型在沒有真實顯示功耗資料時仍顯示 0.00 W 顯示器功耗的問題。
- 無法取得真實顯示功耗時隱藏該項，不再顯示估算值；螢幕關閉或闔蓋時不再殘留舊資料。
- 0 W 的顯示器與 USB 功耗不再顯示為真實功耗。
- 修正應用程式冷啟動時首次讀取闔蓋設定失敗的問題，現在會自動重試。
- 修正應用程式先於背景服務逾時導致誤報的問題；失敗提示會附帶錯誤碼，便於排查。
- 無可用音訊裝置時隱藏音量滑桿，改為顯示「無可用裝置」提示。
- 最佳化英文介面部分文案與長文字顯示，避免被截斷。
