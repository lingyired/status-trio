# 版本 %VERSION%（构建 %BUILD%）

## 传感器与温度

- M3 Air（Mac15,12）GPU 温度恢复：把无法读取的 Tf 传感器换成已验证可读的 Tg 传感器，并按六对分组，避免同一个物理区域被重复计数。
- M5、M6 的 CPU 温度现在会把属于同一核心的多个探针合并；多个探针不再被当成多个核心，也不会抬高平均值。
- 新增 A18 Pro 识别。未知芯片不再借用其他代际的温度 Key；读不到时显示不可用，而不是一个看似合理但错误的数字。

## 显示器功耗

- 修复 Issue #374：没有 PDBR、PBLR 又恒为 0 的 M3 Air，不再显示 0.00 W 的显示器分支。
- 没有可用的实测背光轨道时，直接隐藏显示器分支，不发布估算值。
- 0 W 的显示器与 USB 分支不再绘制成真实功耗。

## 监控与性能

- 传感器能力只探测一次并缓存；不存在的 Key 会退避，不再每次刷新都重试。
- 没有新增常驻定时器、Helper 或特权访问；关闭相关面板后，温度与背光采集仍会停止。
