# 版本 %VERSION%（构建 %BUILD%）

## 新增功能

- 底部指示器新增「内存压力」选项，可直观查看当前内存占用情况。
- 磁盘详情会列出所有已挂载的卷（内置与外接），并分别显示各卷的读写速度；顶部百分比可选择是否计入外接 SSD。
- 硬件监控四个圆环支持进度左右平分显示，顶部百分比不再遮挡进度。
- 硬件详情页新增「打开活动监视器」按钮，可快速查看资源占用来源。
- 高占用 / 高能耗列表支持锁定单行后强制退出（含应用子进程），卡片带刷新倒计时，退出后该项自动移除。

## 问题修复

- 修复 M3 Air GPU 温度无法读取的问题，并避免同一区域的温度被重复计算。
- M5 / M6 的 CPU 温度计算逻辑优化。
- 新增 A18 Pro 芯片识别；无法识别的芯片改为显示不可用，不再给出错误温度。
- 修复部分机型在没有真实显示功耗数据时仍显示 0.00 W 显示器功耗的问题。
- 无法获取真实显示功耗时隐藏该项，不再显示估算值；屏幕关闭或合盖时不再残留旧数据。
- 0 W 的显示器与 USB 功耗不再显示为真实功耗。
- 修复应用冷启动时首次读取合盖设置失败的问题，现在会自动重试。
- 修复应用先于后台服务超时导致误报的问题；失败提示会附带错误码，便于排查。
- 无可用音频设备时隐藏音量滑杆，改为显示「无可用设备」提示。
- 优化英文界面部分文案与长文本显示，避免被截断。
