# Версия %VERSION% (сборка %BUILD%)

## Новые возможности

- В нижнем индикаторе появился пункт «Давление памяти», позволяющий сразу видеть текущее использование памяти.
- В сведениях о диске теперь перечислены все смонтированные тома (внутренние и внешние) со скоростью чтения/записи каждого; верхний процент можно по желанию включать с внешними SSD.
- Четыре кольца монитора оборудования теперь могут делить прогресс на обе стороны, поэтому верхний процент больше не перекрывает кольцо.
- На странице сведений об оборудовании появилась кнопка «Открыть Мониторинг системы», чтобы быстро понять, что расходует ресурсы.
- Список высокой нагрузки / высокого энергопотребления теперь позволяет закрепить строку и принудительно завершить её (вместе с дочерними процессами); на карточках виден обратный отсчёт обновления, а элемент исчезает из списка сразу после завершения.

## Исправления

- Исправлена нечитаемая температура GPU на M3 Air; одна и та же зона больше не учитывается дважды.
- Оптимизирован расчёт температуры CPU для M5 / M6.
- Добавлено распознавание A18 Pro; нераспознанные чипы теперь показывают «недоступно» вместо ошибочной температуры.
- Исправлен случай, когда некоторые модели по-прежнему показывали 0,00 Вт потребления дисплея без реальных показаний.
- Потребление дисплея теперь скрывается при отсутствии реальных показаний вместо оценки; при выключенном экране или закрытой крышке старые значения не остаются.
- Потребление 0 Вт для дисплея и USB больше не отображается как реальное.
- Исправлен сбой первого чтения настройки крышки при холодном запуске; теперь оно повторяется автоматически.
- Исправлен ложный тайм-аут, когда приложение сдавалось раньше фоновой службы; сообщения об ошибке теперь содержат код для диагностики.
- При отсутствии аудиоустройства регулятор громкости скрывается, а вместо него показывается «Нет доступных устройств».
- Доработаны некоторые английские тексты и длинные строки, чтобы они не обрезались.
