# 버전 %VERSION% (빌드 %BUILD%)

### 개선 사항

- 기존 제어 항목, 레이아웃, 탐색을 유지하면서 상태 패널 업데이트의 일관성을 개선했습니다.
- 기기, 네트워크, 오디오 상태가 바뀔 때 패널 표시의 신뢰성을 높였습니다.

### 개인정보

- 선택적 사용 통계를 추가했습니다. 새 설치에서는 기본으로 켜져 있지만 안내를 완료하거나 사용자화하기를 선택하기 전에는 데이터를 보내지 않습니다. 업그레이드에서는 꺼진 상태이며 설정에서 켤 수 있습니다.
- 무작위 설치 ID, 앱 및 macOS 버전, 시스템 및 앱 언어, 아이콘 위치를 전송합니다. 자세한 내용은 [개인정보 및 분석](https://github.com/lingyired/status-trio/blob/main/docs/privacy-telemetry.md)을 참조하세요.
- 타사 분석 SDK는 포함되지 않습니다.
