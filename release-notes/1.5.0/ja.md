# バージョン %VERSION%（ビルド %BUILD%）

### 改善

- コントロール、レイアウト、操作方法を維持しながら、ステータスパネル更新の一貫性を改善しました。
- デバイス、ネットワーク、オーディオの状態変化時に、パネルをより確実に表示します。

### プライバシー

- 任意の利用状況統計を追加しました。新規インストールではオンが初期設定ですが、ガイドを完了するか「カスタマイズ」を選ぶまでデータは送信されません。アップグレードではオフのままで、設定から有効にできます。
- 送信される情報はランダムなインストールID、アプリとmacOSのバージョン、システムとアプリの言語、アイコンの表示場所です。詳しくは[プライバシーと利用状況データ](https://github.com/lingyired/status-trio/blob/main/docs/privacy-telemetry.md)をご覧ください。
- サードパーティ製の分析 SDK は含まれていません。
