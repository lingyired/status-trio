# Версия %VERSION% (сборка %BUILD%)

### Улучшения

- Повышена согласованность обновлений панели состояния при сохранении элементов управления, компоновки и навигации.
- Панель состояния надёжнее отображается при изменениях устройства, сети и аудио.

### Конфиденциальность

- Добавлена необязательная статистика использования. При новой установке опция включена по умолчанию, но данные не отправляются до завершения руководства или выбора настройки. После обновления функция выключена, пока вы не включите её в настройках.
- Heartbeat содержит случайный ID установки, версии приложения и macOS, языки системы и приложения, а также расположение значка. Подробнее: [конфиденциальность и аналитика](https://github.com/lingyired/status-trio/blob/main/docs/privacy-telemetry.md).
- Сторонние SDK аналитики не используются.
