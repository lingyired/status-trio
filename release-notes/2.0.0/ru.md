# Версия %VERSION% (сборка %BUILD%)

### Новые возможности

- Настраивайте значки строки меню и Dock в одном редакторе, выбирая отдельные источники для внешнего кольца, центра и нижней части.
- Задавайте основной и необязательный резервный источник для каждой области и смотрите, почему источник отображается или недоступен.
- Просматривайте текущий статус и поддерживаемые сценарии с теми же параметрами отрисовки, что используются в строке меню и Dock.
- Настраивайте внешний вид и поведение значка, сохраняя прежние параметры устройств, панели и системы.

- Используйте аккумулятор AirPods как источник кольца: одно кольцо или отдельные левое/правое кольца. Если данные есть только для одного наушника, показывается только его известный заряд; заряд кейса не заменяет наушник.
- Выберите подключённое устройство Bluetooth для центра. Выбор сохранится при отключении устройства; если задан резервный источник, будет использован он.

### Доступность и конфиденциальность

- Элементы областей значка передают вспомогательным технологиям название, источник и состояние выбора.
- Предпросмотр учитывает «Уменьшение движения» и останавливает анимацию при скрытии редактора.
- Предпросмотр сценариев использует примеры и не запускает дополнительный мониторинг устройств.
