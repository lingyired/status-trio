# Version %VERSION% (Build %BUILD%)

### New features

- Design the menu bar and Dock icons from one Icon Designer, with separate outer-ring, center, and footer sources.
- Choose a preferred source and an optional fallback for each icon slot; see why a source is shown or unavailable.
- Preview real status and supported scenarios using the same rendering configuration as the menu bar and Dock.
- Customize icon appearance and behavior while keeping existing device, panel, and system settings available.

- Use AirPods battery as the ring source in a single-ring or separate left/right dual-ring layout. If only one earbud has a reading, show only that known ear; case charge never substitutes for an earbud.
- Choose a connected Bluetooth device for the center source. The choice stays configured when the device disconnects, and an optional configured fallback is used.

### Accessibility and privacy

- Icon slot controls expose their name, source, and selection state to assistive technologies.
- Previews respect Reduce Motion and stop their animation when the Designer is hidden.
- Scenario previews use sample values and do not start additional device monitoring.
