# 版本 %VERSION%（构建 %BUILD%）

### 新功能

- 在统一的图标设计器中配置菜单栏和 Dock 图标，并分别选择外环、中心与底部区域的来源。
- 为每个图标区域选择首选来源和可选备用来源，并查看当前显示或来源不可用的原因。
- 使用与菜单栏和 Dock 相同的渲染配置预览实时状态及支持的场景。
- 自定义图标外观和行为，同时保留现有设备、面板和系统设置。

- 可将 AirPods 电池设为外环来源，并选择单圆环或左右双圆环；若只有一侧耳机有电量数据，仅显示已知的一侧，不用充电盒电量代替。
- 可选择已连接的蓝牙设备作为中心来源。设备断开后仍保留该配置；若设置了备用来源，则按备用来源回退。

### 无障碍与隐私

- 图标区域控件会向辅助技术提供名称、来源和选中状态。
- 预览遵循“减少动态效果”设置，并在设计器隐藏时停止动画。
- 场景预览使用模拟值，不会启动额外的设备监控。
