# バージョン %VERSION%（ビルド %BUILD%）

### 新機能

- 1つのアイコンデザイナーでメニューバーとDockのアイコンを設定し、外周リング、中央、フッターのソースを個別に選べます。
- 各領域の優先ソースと任意の代替ソースを選び、表示理由や利用できない理由を確認できます。
- メニューバーとDockと同じ描画設定で、実際の状態や対応シナリオをプレビューできます。
- 既存のデバイス、パネル、システム設定を保ちながら、アイコンの外観と動作をカスタマイズできます。

- AirPods のバッテリーをリングのソースに設定し、シングルまたは左右別々のデュアルリングで表示できます。片耳分だけ取得できる場合はその側だけを表示し、ケースの残量で代用しません。
- 接続中の Bluetooth デバイスを中央のソースに選択できます。切断後も選択設定は保持され、予備ソースを設定している場合はそちらに切り替わります。

### アクセシビリティとプライバシー

- アイコン領域の名前、ソース、選択状態を支援技術に伝えます。
- プレビューは「視差効果を減らす」に対応し、デザイナーが非表示になるとアニメーションを停止します。
- シナリオプレビューはサンプル値を使い、追加のデバイス監視を開始しません。
