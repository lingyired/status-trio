# 版本 %VERSION%（建置 %BUILD%）

### 新功能

- 在同一個圖示設計器中設計選單列與 Dock 圖示，並分別選擇外環、中央與底部區域的來源。
- 為每個圖示區域選擇偏好來源與選用的備援來源，並查看目前顯示或來源無法使用的原因。
- 使用與選單列及 Dock 相同的繪製設定，預覽即時狀態與支援的情境。
- 自訂圖示外觀與行為，同時保留現有的裝置、面板和系統設定。

- 可將 AirPods 電池設為外環來源，並選擇單圓環或左右雙圓環；若只有一側耳機有電量資料，只顯示已知的一側，不以充電盒電量代替。
- 可選擇已連線的 Bluetooth 裝置作為中央來源。裝置中斷連線後仍保留此設定；若已設定備援來源，則依備援來源回退。

### 輔助使用與隱私權

- 圖示區域控制項會向輔助科技提供名稱、來源與選取狀態。
- 預覽遵循「減少動態效果」設定，並在設計器隱藏時停止動畫。
- 情境預覽使用範例值，不會啟動額外的裝置監控。
