# 버전 %VERSION% (빌드 %BUILD%)

### 새로운 기능

- 하나의 아이콘 디자이너에서 메뉴 막대와 Dock 아이콘을 설계하고 바깥 링, 중앙, 하단의 소스를 각각 선택할 수 있습니다.
- 각 아이콘 영역의 기본 소스와 선택적 대체 소스를 지정하고 소스가 표시되거나 사용할 수 없는 이유를 확인하세요.
- 메뉴 막대와 Dock에 적용되는 것과 동일한 렌더링 설정으로 실제 상태와 지원 시나리오를 미리 볼 수 있습니다.
- 기존 기기, 패널, 시스템 설정을 유지하면서 아이콘 모양과 동작을 사용자화할 수 있습니다.

- AirPods 배터리를 링 소스로 선택해 단일 링 또는 좌우 듀얼 링으로 표시할 수 있습니다. 한쪽 이어버드만 확인되면 해당 값만 표시하며 케이스 배터리로 대체하지 않습니다.
- 연결된 Bluetooth 기기를 중앙 소스로 선택할 수 있습니다. 연결이 끊겨도 선택 설정은 유지되며, 선택적 대체 소스를 설정한 경우 해당 소스로 전환됩니다.

### 접근성 및 개인정보 보호

- 아이콘 영역 컨트롤은 이름, 소스, 선택 상태를 보조 기술에 전달합니다.
- 미리보기는 동작 줄이기를 따르며 디자이너가 숨겨지면 애니메이션을 중지합니다.
- 시나리오 미리보기는 예시 값을 사용하며 추가 기기 모니터링을 시작하지 않습니다.
