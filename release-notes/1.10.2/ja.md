# バージョン %VERSION%（ビルド %BUILD%）

### システムモニター

- ステータスパネルに CPU・GPU・メモリ・ネットワーク・ディスク・ファン回転数の監視を追加し、クリックで各詳細ページを開けます。
- CPU・GPU・メモリ・ネットワーク・ディスク・ファン回転数の指標ごとに配色をカスタマイズできます。
- 更新間隔と履歴の保持時間をカスタマイズできます。
- システムモニターは必要なときだけサンプリングします。実際に表示している間だけ読み取り、バックグラウンド履歴は既定でオフになり、バックグラウンド負荷を抑えます。

### メニューバーアイコンとリング

- 外側リングにシステムモニターのデータソースを追加し、単一リングと左右デュアルリングのレイアウトに対応しました。リングには CPU 使用率、CPU 温度、GPU 使用率、GPU 温度、メモリ使用率、バッテリー温度、バッテリー残量、ファン回転数、ダウンロード速度、アップロード速度、音量、Wi-Fi 信号を使用できます。
- リングのバッテリー残量アークはシステムのバッテリー配色に従い、「放電（電源未接続）」の色ロールを追加しました。充電中・低電力・高電力・危険・放電の色を個別に設定できます（#357）。
- 上部インジケーターに AirPods モードを追加しました。左右のデュアルリングで左右のイヤホン残量を表示でき（片耳にも対応）、切断時は Mac のバッテリーまたはカスタムリングにフォールバックします。
- 下部インジケーターはデータソースをカスタマイズでき、現在は音量・Wi-Fi 信号・バッテリー残量（または非表示）に対応しています。

### パネルと操作

- メニューバーアイコンにカーソルを合わせるとパネルが開き、クリックで固定できます（#355）。
- 詳細はステータスパネルの横のサイドパネルで開くようになり、切り替えが滑らかになりました。
- ハードウェアモニターのカードを追加しました。
- 数値スライダー（音量・明るさ）の UI を macOS 26+ に近づけ、動きを滑らかにしました。トラックパッドの左右スワイプで調整できます（#351）。
- Wi-Fi と Bluetooth のアイコンを接続状態に応じて着色します（#352）。
- 「今すぐ満充電」ボタンに Liquid Glass のホバー光沢を追加しました。
- ステータスパネルの太字を廃止し、数値と単位を等幅フォントにしました。

### スリープ防止

- 「画面をオンのまま」と「フタを閉じてもスリープしない」を追加し、それぞれ時間を設定できます（#295）。

### 明るさ

- 「BetterDisplay の合成輝度を使用」スイッチを追加しました（#344）。

### バッテリーとオーディオ

- 100% 時のトリクル充電の文言と充電行を修正しました。
- 音量がちょうどゼロのときにミュートできない問題と、自動ミュートの復元異常を修正しました。
- 「満充電までの時間」が macOS の充電上限を考慮するよう修正しました（#349）。

### その他の修正

- モニター詳細の履歴が指標ごとに分離されない問題を修正しました。
- バックグラウンドのサンプリングとプロセスパイプの安定性を改善し、パネルのカクつきと混線を減らしました。
- パネルを開くときに AirPods のリスニングモード行の高さがちらつく問題を修正しました（#354）。
