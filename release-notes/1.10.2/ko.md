# 버전 %VERSION% (빌드 %BUILD%)

### 시스템 모니터

- 상태 패널에 CPU, GPU, 메모리, 네트워크, 디스크, 팬 속도 모니터링을 추가했으며, 항목을 클릭하면 해당 상세 페이지가 열립니다.
- CPU, GPU, 메모리, 네트워크, 디스크, 팬 속도 지표의 색상을 사용자 지정할 수 있습니다.
- 업데이트 주기와 기록 보관 시간을 설정할 수 있습니다.
- 시스템 모니터는 필요할 때만 샘플링합니다. 실제로 표시되는 동안에만 읽고 백그라운드 기록은 기본적으로 꺼져 있어 백그라운드 부하를 줄입니다.

### 메뉴 막대 아이콘과 링

- 바깥 링에 시스템 모니터 데이터 소스를 추가했고, 단일 링과 좌우 듀얼 링 레이아웃을 지원합니다. 링에는 CPU 사용량, CPU 온도, GPU 사용량, GPU 온도, 메모리 사용량, 배터리 온도, 배터리 잔량, 팬 속도, 다운로드 속도, 업로드 속도, 볼륨, Wi-Fi 신호를 사용할 수 있습니다.
- 링의 배터리 잔량 호는 시스템 배터리 색상을 따르며, 새로운 "방전(전원 미연결)" 색상 역할로 충전, 저전력, 고전력, 위험, 방전 색상을 각각 지정할 수 있습니다(#357).
- 상단 표시기에 AirPods 모드를 추가했습니다. 좌우 듀얼 링으로 양쪽 이어폰 잔량을 표시할 수 있고(한쪽 이어폰도 지원), 연결이 끊기면 Mac 배터리나 사용자 지정 링으로 대체됩니다.
- 하단 표시기는 데이터 소스를 사용자 지정할 수 있으며, 현재 볼륨, Wi-Fi 신호, 배터리 잔량(또는 숨김)을 지원합니다.

### 패널과 상호작용

- 메뉴 막대 아이콘에 커서를 올리면 패널이 열리고, 클릭하면 고정됩니다(#355).
- 상세 정보가 상태 패널 옆의 사이드 패널로 열리며 전환이 더 부드러워졌습니다.
- 하드웨어 모니터 카드를 추가했습니다.
- 숫자 슬라이더(볼륨, 밝기) UI를 macOS 26+에 가깝게 다듬고 움직임을 부드럽게 했습니다. 트랙패드 좌우 스와이프로 조절할 수 있습니다(#351).
- Wi-Fi와 Bluetooth 아이콘이 연결 상태에 따라 색상이 적용됩니다(#352).
- "지금 완충" 버튼에 리퀴드 글래스 호버 광택을 추가했습니다.
- 상태 패널의 굵은 글씨를 제거하고 값과 단위를 고정폭 글꼴로 변경했습니다.

### 화면 유지와 잠자기

- "화면 켜 두기"와 "덮개 닫아도 잠자지 않기"를 추가했으며 각각 시간을 설정할 수 있습니다(#295).

### 밝기

- "BetterDisplay 복합 밝기 사용" 스위치를 추가했습니다(#344).

### 배터리와 오디오

- 100%에서의 미세 충전 문구와 충전 행을 수정했습니다.
- 볼륨이 정확히 0일 때 음소거되지 않는 문제와 자동 음소거 복원 오류를 수정했습니다.
- "완충까지 남은 시간"이 macOS 충전 한도를 반영하도록 수정했습니다(#349).

### 기타 수정

- 모니터 상세 기록이 지표별로 분리되지 않는 문제를 수정했습니다.
- 백그라운드 샘플링과 프로세스 파이프 안정성을 개선하여 패널 끊김과 혼선을 줄였습니다.
- 패널을 열 때 AirPods 리스닝 모드 행 높이가 깜빡이는 문제를 수정했습니다(#354).
