# Version %VERSION% (Build %BUILD%)

## Icons & Rings

- The bottom indicator in the menu bar and Dock can now show CPU, GPU, memory, temperatures, fan speed or upload and download speeds, with a separate four-dot or arc style for each source.
- Choose a preset or custom color for the volume indicator when using Bluetooth headphones or speakers.
- Restored the full battery ring on Macs without a battery, including Mac Studio (#366).

## Status Panel

- Volume and microphone sliders can match the brightness slider's thickness, brightness labels stay on the left with text that adapts to the fill, and the new pill-shaped thumb takes on a glass appearance while dragged on Liquid Glass panels (#368).
- Clicking the same detail entry again returns to the summary and keeps the main panel open (#369).

## System Monitor

- CPU and GPU temperature monitoring can be turned off, the CPU ring can show an estimated clock speed, and Macs with the original M1 chip can try a fallback sensor when normal temperature readings fail; that fallback can use noticeably more CPU, so turn temperature monitoring off if you don't need it.
- Adjust warning thresholds, display ranges or network speed limits for the relevant metrics in System Monitor and Bottom Indicator settings.
- CPU, GPU, memory and network top-app lists now sort by current usage on every refresh (#370).

## Power & App Size

- The power helper no longer checks approval on a regular timer while idle, reducing system code-signature checks (#367).
- Reduced the size of the installed app.
