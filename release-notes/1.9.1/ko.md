# 버전 %VERSION%(빌드 %BUILD%)

### 배터리

- 배터리 상세에 전력 흐름(내장 디스플레이, USB/액세서리 출력, 시스템)과 선택형 실시간 전력 바를 추가했습니다. 액세서리 출력은 가능한 경우 SMC 포트에서 읽습니다.
- "지금 완충"에 "취소 후 상한 복원" 설정을 추가하고, macOS가 자체적으로 임시 재정의를 시작할 때의 상태 표시를 개선했습니다.
- 배터리 아이콘 색상을 사용자 상태 색으로 지정하고 연결 표시(번개·플러그·퍼센트)를 따로 선택할 수 있습니다.
- 배터리 링에 선택형 "분할" 모드를 추가했습니다. 상단 틈에 번개·플러그·퍼센트가 표시될 때 왼쪽 호는 0–50%, 오른쪽 호는 50–100%를 나타내 40–60%가 가려지지 않습니다. 기본값은 꺼짐이며 메뉴 막대와 Dock에 모두 적용됩니다.

### 전원

- 중앙 슬롯에 연결 소스 대신 시스템 전체의 실시간 전력을 표시할 수 있으며, 내장 배터리가 없는 Mac도 지원합니다.

### 디스플레이

- 디스플레이 밝기 조절을 추가했습니다. 외장은 직접 DDC, 내장은 DisplayServices로 직접 제어합니다.

### 중앙 아이콘

- 중앙 슬롯 소스를 "중앙 아이콘" 선택기 하나로 통합했습니다: 네트워크, Bluetooth 기기, 현재 입력 소스, 배터리 잔량, 전력. 네트워크 오류 스위치 두 개는 모든 소스에 적용되는 하나로 합쳐졌고, 동작하지 않던 Bluetooth "네트워크 아이콘 바꾸기" 토글은 제거되었으며 기존 설정은 자동 이전됩니다.
- 중앙 아이콘 소스가 실제 렌더링을 미리 보여 주는 이미지 타일로 바뀌었습니다. "중앙 아이콘 크기" 하나가 Wi‑Fi, Bluetooth, 입력 소스, 숫자를 함께 제어하며 네트워크 아이콘 스타일 옵션도 같은 페이지로 옮겼습니다.
- 중앙 아이콘 미리보기에 충전 상태가 표시되고, 중앙 내용이 배터리 링 위에서 세로로 올바르게 중앙 정렬됩니다. 글자는 기호보다 약간 작습니다.

### 가이드

- 온보딩 개편: 창이 가장 높은 페이지에 맞춰 크기가 정해지고 단계 전환 시 크기가 바뀌지 않습니다. 미리보기를 한 면에 모으고 상단 호·중앙 아이콘·하단 점 설명을 추가했으며, 중앙 슬롯 예시(잔량·전력·입력 소스)를 넣고 동의 블록을 더 간결하게 했습니다.

### 설정

- 모든 설정 팝업 메뉴가 하나의 너비를 사용하며 항목이나 기기 목록에 따라 너비가 바뀌지 않고, 네이티브 팝업 모양을 유지합니다.

### 오디오

- 입력/출력 기기를 정렬·숨김·표시 개수 제한할 수 있습니다.
- 스크롤 휠 볼륨 피드백을 따로 설정할 수 있고, 선택한 청취 모드를 다시 클릭하면 꺼집니다.

### 패널

- 상태 패널을 모서리 없는 스타일로 바꾸고 하단 "더 보기" 메뉴를 추가했으며 Liquid Glass에서 크기와 레이아웃을 개선했습니다.

### 수정

- 위치 권한이 없어도 확인 가능한 Wi-Fi 연결 정보를 표시합니다.
