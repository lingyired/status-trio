# 版本 %VERSION%（組建 %BUILD%）

### 設定

- 設定介面全新改版，分類更清楚、更容易找到；圖示相關設定統一收進「應用程式圖示」。
- 新增「亮度」頁：可逐台選擇哪些顯示器顯示在狀態面板，也可選 BetterDisplay 作為亮度控制後端（#241、#239）。

### 面板

- 音量、亮度換成統一的膠囊滑桿，點一下或拖曳即可調節；音量、亮度、音訊輸入都支援滾輪調節（#245、#213、#256）。
- 修正調節音量時 CPU 短暫飆升的問題（#263）。
- 面板動態高度和捲軸更穩定（#283）。
- 新增「每次開啟面板回到主介面」開關（#262）。
- 修正點開設定後再點設定視窗、狀態面板不消失的問題（#267）。
- 亮度那一列加了齒輪按鈕，可直接開啟系統「顯示器」設定；滾輪調亮度即時生效。

### 選單列與圖示

- 新增「充電狀態顯示在圓環內部」選項：頂部圓環保留，插電時中間圖示改為充電狀態（#253）。
- 修正充電動畫經過頂部間隙時左側留下漸層尾巴（#254）。
- Dock 圖示底板對齊系統網格，不再顯得比其他應用程式大（#260）。

### 電池與電源

- 新增高功率模式，像低耗電模式一樣一鍵切換（#235）。
- 增加自動開啟低耗電模式（#246）。

### Wi-Fi 與網路

- Wi-Fi 摘要列加了電源開關（預設顯示），關閉已連線網路前會確認（#252）。
- Wi-Fi 名稱權限：詳細頁改成明顯按鈕，網路設定頂部加了權限區；沒有定位權限時會提示並可直接授權（#247、#276）。
- 修正開啟 Wi-Fi 詳細頁後高 CPU / 卡死的問題（#259）。

### 藍牙、Apple Watch 與 AirPods

- 改進 AirPods 電量顯示，修正串台問題（#248）。
- 改進 Apple Watch 電量顯示與探索診斷（#249）。
- 修正關閉藍牙後仍顯示快取裝置和連線標記的問題（#265）。
- 說明：藍牙相關的電量修正（AirPods、Apple Watch 等）仍在持續跟進，後續版本會繼續完善。

### 安裝

- 安裝程式預設使用新的拖曳安裝頁（中英文說明 + 箭頭引導）（#244）。

### 修正

- 修正一個監控程序退出時讀取管道的偶發問題（#268）。
- 聆聽模式開關現在也對華為耳機生效。
