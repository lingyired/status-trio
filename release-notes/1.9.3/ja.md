# バージョン %VERSION%（ビルド %BUILD%）

### 設定

- 設定画面を全面的に刷新し、カテゴリをより分かりやすく整理しました。アイコン関連の設定は「アプリアイコン」にまとめています。
- 「輝度」ページを追加：ディスプレイごとにステータスパネルへ表示するかを選べ、輝度制御のバックエンドとして BetterDisplay も選択できます（#241、#239）。

### パネル

- 音量と輝度を統一されたカプセルスライダーに変更しました。クリックまたはドラッグで調整でき、音量・輝度・オーディオ入力はスクロールでも調整できます（#245、#213、#256）。
- 音量調整時に CPU が一瞬急上昇する問題を修正しました（#263）。
- パネルの動的な高さとスクロールバーをより安定させました（#283）。
- 「パネルを開くたびにメイン画面に戻る」スイッチを追加しました（#262）。
- 設定を開いた後に設定ウインドウをクリックしてもステータスパネルが消えない問題を修正しました（#267）。
- 輝度の行にギアボタンを追加し、システムの「ディスプレイ」設定を直接開けるようにしました。スクロールでの輝度調整は即時反映されます。

### メニューバーとアイコン

- 「充電状態をリングの内側に表示」オプションを追加しました。上部のリングは残り、電源接続時は中央のアイコンが充電状態に切り替わります（#253）。
- 充電アニメーションが上部の隙間を通過する際に左側へ残るグラデーションの尾を修正しました（#254）。
- Dock アイコンの台座をシステムのグリッドに合わせ、他のアプリより大きく見えないようにしました（#260）。

### バッテリーと電源

- 低電力モードと同じようにワンクリックで切り替えられる高電力モードを追加しました（#235）。
- 低電力モードの自動有効化を追加しました（#246）。

### Wi-Fi とネットワーク

- Wi-Fi の概要行に電源スイッチを追加しました（既定で表示）。接続中のネットワークをオフにする前には確認を求めます（#252）。
- Wi-Fi 名の権限：詳細ページを目立つボタンに変更し、ネットワーク設定の上部に権限エリアを追加しました。位置情報の権限がない場合は案内が表示され、その場で許可できます（#247、#276）。
- Wi-Fi の詳細ページを開いた後の高 CPU / フリーズ問題を修正しました（#259）。

### Bluetooth、Apple Watch、AirPods

- AirPods のバッテリー表示を改善し、値の混在を修正しました（#248）。
- Apple Watch のバッテリー表示と検出診断を改善しました（#249）。
- Bluetooth をオフにした後もキャッシュされたデバイスや接続マークが表示される問題を修正しました（#265）。
- 補足：Bluetooth 関連のバッテリー修正（AirPods、Apple Watch など）は引き続き対応中で、今後のバージョンでさらに改善します。

### インストール

- インストーラは新しいドラッグ＆ドロップのインストール画面（中国語・英語の説明＋矢印ガイド）を既定で使用します（#244）。

### 修正

- 監視プロセスの終了時にパイプを読み取る際のまれな問題を修正しました（#268）。
- リスニングモードのスイッチが Huawei のイヤホンにも有効になりました。
