# 版本 %VERSION%（构建 %BUILD%）

### 设置

- 设置界面全新改版，分类更清晰、更容易找到；图标相关设置统一收进「应用图标」。
- 新增「亮度」页：可逐台选择哪些显示器显示在状态面板，也可选 BetterDisplay 作为亮度控制后端（#241、#239）。

### 面板

- 音量、亮度换成统一的胶囊滑杆，点一下或拖动即可调节；音量、亮度、音频输入都支持滚轮调节（#245、#213、#256）。
- 修复调节音量时 CPU 短暂飙升的问题（#263）。
- 面板动态高度和滚动条更稳定（#283）。
- 新增「每次打开面板回到主界面」开关（#262）。
- 修复点开设置后再点设置窗口、状态面板不消失的问题（#267）。
- 亮度那一行加了齿轮按钮，可直接打开系统「显示器」设置；滚轮调亮度即时生效。

### 菜单栏与图标

- 新增「充电状态显示在圆环内部」选项：顶部圆环保留，插电时中间图标改为充电状态（#253）。
- 修复充电动画经过顶部间隙时左侧留下渐变尾巴（#254）。
- Dock 图标底板对齐系统网格，不再显得比其他应用大（#260）。

### 电池与电源

- 新增高功率模式，像低电量模式一样一键切换（#235）。
- 增加自动开启低电量模式（#246）。

### Wi-Fi 与网络

- Wi-Fi 摘要行加了电源开关（默认显示），关闭已连接网络前会确认（#252）。
- Wi-Fi 名称权限：详情页改成明显按钮，网络设置顶部加了权限区；没有定位权限时会提示并可直接授权（#247、#276）。
- 修复打开 Wi-Fi 详情页后高 CPU / 卡死的问题（#259）。

### 蓝牙、Apple Watch 与 AirPods

- 改进 AirPods 电量显示，修复串台问题（#248）。
- 改进 Apple Watch 电量显示与发现诊断（#249）。
- 修复关闭蓝牙后仍显示缓存设备和连接标记的问题（#265）。
- 说明：蓝牙相关的电量修复（AirPods、Apple Watch 等）仍在持续跟进，后续版本会继续完善。

### 安装

- 安装包默认使用新的拖拽安装页（中英文说明 + 箭头引导）（#244）。

### 修复

- 修复一个监控进程退出时读取管道的偶发问题（#268）。
- 聆听模式开关现在也对华为耳机生效。
