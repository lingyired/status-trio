# 버전 %VERSION% (빌드 %BUILD%)

### 설정

- 설정 화면을 전면 개편하여 카테고리가 더 명확하고 찾기 쉬워졌습니다. 아이콘 관련 설정은 「앱 아이콘」으로 통합했습니다.
- 「밝기」 페이지 추가: 디스플레이별로 상태 패널에 표시할지 선택할 수 있고, 밝기 제어 백엔드로 BetterDisplay도 선택할 수 있습니다 (#241, #239).

### 패널

- 볼륨과 밝기를 통일된 캡슐 슬라이더로 변경했습니다. 클릭하거나 드래그해 조절할 수 있으며, 볼륨·밝기·오디오 입력 모두 스크롤로 조절할 수 있습니다 (#245, #213, #256).
- 볼륨 조절 시 CPU가 잠깐 급등하는 문제를 수정했습니다 (#263).
- 패널의 동적 높이와 스크롤바가 더 안정적으로 동작합니다 (#283).
- 「패널을 열 때마다 메인 화면으로 돌아가기」 스위치를 추가했습니다 (#262).
- 설정을 연 뒤 설정 창을 다시 클릭해도 상태 패널이 사라지지 않던 문제를 수정했습니다 (#267).
- 밝기 행에 톱니바퀴 버튼을 추가해 시스템 「디스플레이」 설정을 바로 열 수 있습니다. 스크롤로 밝기를 조절하면 즉시 반영됩니다.

### 메뉴 막대 및 아이콘

- 「충전 상태를 링 안쪽에 표시」 옵션을 추가했습니다. 상단 링은 유지되고, 전원 연결 시 가운데 아이콘이 충전 상태로 바뀝니다 (#253).
- 충전 애니메이션이 상단 틈을 지날 때 왼쪽에 남던 그라데이션 꼬리를 수정했습니다 (#254).
- Dock 아이콘 받침판을 시스템 그리드에 맞춰 다른 앱보다 커 보이지 않게 했습니다 (#260).

### 배터리 및 전원

- 저전력 모드처럼 한 번에 전환할 수 있는 고전력 모드를 추가했습니다 (#235).
- 저전력 모드 자동 켜기를 추가했습니다 (#246).

### Wi-Fi 및 네트워크

- Wi-Fi 요약 행에 전원 스위치를 추가했습니다(기본 표시). 연결된 네트워크를 끄기 전에는 확인을 거칩니다 (#252).
- Wi-Fi 이름 권한: 상세 페이지를 눈에 띄는 버튼으로 바꾸고 네트워크 설정 상단에 권한 영역을 추가했습니다. 위치 권한이 없으면 안내가 표시되고 바로 허용할 수 있습니다 (#247, #276).
- Wi-Fi 상세 페이지를 연 뒤 CPU가 높아지거나 멈추는 문제를 수정했습니다 (#259).

### Bluetooth, Apple Watch 및 AirPods

- AirPods 배터리 표시를 개선하고 값이 뒤섞이는 문제를 수정했습니다 (#248).
- Apple Watch 배터리 표시와 검색 진단을 개선했습니다 (#249).
- Bluetooth를 끈 뒤에도 캐시된 기기와 연결 표시가 남던 문제를 수정했습니다 (#265).
- 참고: Bluetooth 관련 배터리 수정(AirPods, Apple Watch 등)은 계속 진행 중이며 이후 버전에서 더 개선될 예정입니다.

### 설치

- 설치 프로그램이 기본으로 새로운 드래그 앤 드롭 설치 화면(중국어·영어 설명 + 화살표 안내)을 사용합니다 (#244).

### 수정

- 모니터링 프로세스 종료 시 파이프를 읽는 간헐적 문제를 수정했습니다 (#268).
- 청취 모드 스위치가 이제 Huawei 이어폰에도 적용됩니다.
