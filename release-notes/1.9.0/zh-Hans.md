# 版本 %VERSION%（构建 %BUILD%）

### 电池

- 新增默认关闭的原生充电上限选择，适用于搭载 Apple 芯片、运行 macOS 26.4 或更高版本的兼容 Mac。可选择系统提供的档位，重启应用后保留，并通过「由系统管理」恢复接管前记录的上限。
- 自定义上限会在启动、唤醒和电源状态变化后重新应用，不新增轮询。「立即充满」会临时暂停上限，取消、充满或重新接通电源后恢复；检测到外部上限变化时暂停管理，需重新选择或点击「重新应用」后继续。
- 写入与恢复均需回读确认，中断的操作会保留恢复记录。此功能依赖私有 PowerUI 接口，实际行为取决于 macOS 和硬件。
- 新增可选的电池圆环“劈开”模式。当顶部缺口显示闪电、插头或电量数字时，左侧可见弧对应 0–50%、右侧对应 50–100%，40%–60% 之间的电量不再被缺口遮住。该选项默认关闭，菜单栏与程序坞同时生效。
