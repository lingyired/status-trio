# 버전 %VERSION%(빌드 %BUILD%)

### 배터리

- 배터리 링에 선택형 "분할" 모드를 추가했습니다. 상단 틈에 번개·플러그·퍼센트가 표시될 때 왼쪽 호는 0–50%, 오른쪽 호는 50–100%를 나타내 40–60%가 가려지지 않습니다. 기본값은 꺼짐이며 메뉴 막대와 Dock에 모두 적용됩니다.
- 배터리 아이콘 색상을 사용자 상태 색으로 지정하고 연결 표시(번개·플러그·퍼센트)를 따로 선택할 수 있습니다. 메뉴 막대와 Dock은 같은 장면을 공유합니다.
- 배터리 상세에 전력 흐름(내장 디스플레이, USB/액세서리 출력, 시스템)과 선택형 실시간 전력 바를 추가했습니다. 액세서리 출력은 가능한 경우 SMC 포트에서 읽습니다.
- "지금 완충"에 "취소 후 상한 복원" 설정을 추가하고, macOS가 자체적으로 임시 재정의를 시작할 때의 상태 표시를 개선했습니다.

### 전원

- 중앙 슬롯에 연결 소스 대신 시스템 전체의 실시간 전력을 표시할 수 있으며, 내장 배터리가 없는 Mac도 지원합니다.

### 디스플레이

- 디스플레이 밝기 조절을 추가했습니다. 외장은 직접 DDC, 내장은 DisplayServices로 직접 제어하므로 내장 화면에 BetterDisplay가 필요 없습니다.
- 전력 흐름도에서 모든 분기의 카드 높이가 비율에 비례합니다(분기 수와 무관).

### 오디오

- 입력/출력 기기를 정렬·숨김·표시 개수 제한할 수 있습니다. 청취 모드를 지원하는 기기가 하나만 남아도 다른 출력을 숨겼을 때 노이즈 컨트롤 버튼이 유지됩니다.
- 스크롤 휠 볼륨 피드백을 따로 설정할 수 있고, 선택한 청취 모드를 다시 클릭하면 꺼집니다.

### 패널

- 상태 패널을 모서리 없는 스타일로 바꾸고 하단 "더 보기" 메뉴를 추가했으며 Liquid Glass에서 크기와 레이아웃을 개선했습니다. 기본 순서에서 "디스플레이 밝기"는 "오디오 입력" 아래에 있습니다.

### 수정

- "지금 완충" 중에 재시작해도 처음 계산한 복원 상한을 유지하며 100%로 되돌아가지 않습니다.
- 상태 패널을 닫으면 전력 정보 바 샘플링을 해제합니다. 아이콘이 전력을 표시하는 동안에만 2초마다 샘플링합니다.
- 패널을 연 상태에서 전력 정보 바를 전환하면 새 값을 즉시 사용합니다.
- 전원을 뽑아도 검증된 배터리 전력 흐름을 버리지 않습니다.
- 디스플레이 핫플러그 시 밝기 목록을 새로 고치고 오래된 DDC 연결을 폐기합니다.
- DDC 밝기 쓰기가 읽기로 확인되지 않으면 슬라이더와 설명을 모두 잃는 대신 "사용할 수 없음"을 표시합니다.
- 위치 권한이 없어도 확인 가능한 Wi-Fi 연결 정보를 표시합니다.
