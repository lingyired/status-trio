# Версия %VERSION% (сборка %BUILD%)

### Аккумулятор

- Необязательный режим «разделения» кольца батареи: если в верхнем разрыве показаны молния, вилка или процент, левая дуга означает 0–50 %, правая — 50–100 %, поэтому 40–60 % больше не скрывается. По умолчанию выключено; действует для строки меню и Dock.
- Цвета значка батареи могут следовать пользовательским цветам состояния, с отдельным выбором индикатора подключения (молния, вилка или процент). Строка меню и Dock используют одну сцену.
- Страница батареи показывает разбивку потока мощности (встроенный экран, USB/аксессуары и система) и необязательную строку мощности в реальном времени. Выход на аксессуары читается с портов SMC, когда доступно.
- Новый параметр «Восстанавливать лимит после отмены» для «Зарядить до полного», с более понятными состояниями, когда macOS сама включает временное переопределение.

### Питание

- В центральном слоте можно показывать общую мощность в реальном времени вместо источника подключения; Mac без встроенной батареи полностью поддерживаются.

### Дисплеи

- Регулировка яркости: внешние дисплеи используют прямой DDC, встроенные управляются через DisplayServices, поэтому BetterDisplay для встроенного экрана больше не нужен.
- На схеме потока высота каждой карточки пропорциональна её доле при любом числе ветвей.

### Аудио

- Устройства ввода/вывода можно упорядочивать, скрывать и ограничивать по количеству. Единственное устройство с режимом прослушивания сохраняет кнопки шумоподавления, даже если другие выходы скрыты.
- Обратная связь громкости колесом настраивается отдельно; повторное нажатие выбранного режима прослушивания отключает его.

### Панель

- Панель состояния получила стиль без скруглений и выступа, нижнее меню «ещё» и лучше подстраивает размер и компоновку в Liquid Glass. В порядке по умолчанию «Яркость дисплея» находится под «Аудиовходом».

### Исправления

- Перезапуск во время «Зарядить до полного» сохраняет изначально вычисленный лимит восстановления вместо возврата к 100 %.
- Закрытие панели освобождает выборку строки мощности; значок выбирает данные каждые 2 с только пока показывает мощность.
- Переключение строки мощности при открытой панели сразу использует новое значение.
- Проверенная разбивка мощности батареи больше не теряется при отключении питания.
- Горячее подключение дисплея обновляет список яркости и отбрасывает устаревшее DDC-соединение.
- Неподтверждённая запись яркости DDC показывает «недоступно» вместо потери ползунка и пояснения.
- Сведения о Wi‑Fi по-прежнему показываются без разрешения на геолокацию.
