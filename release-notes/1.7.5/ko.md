# 버전 %VERSION%(빌드 %BUILD%)

### 새로운 기능 및 개선 사항

- macOS 26 이상에서 Finder와 Launchpad의 앱 아이콘이 시스템의 라이트/다크 모양을 따릅니다. macOS 13–15에서는 계속 라이트 아이콘이 표시됩니다.
- Apple 기기 배터리 읽기를 개선했습니다. macOS가 인식하는 기기 이름으로 Bluetooth 기기를 확인하고 읽기에 반복해서 실패하면 재시도를 일시 중지하여 관련 없는 기기와 불필요한 페어링 요청의 영향을 줄입니다.
- 키보드 탐색이 켜져 있을 때 상태 패널을 열어도 첫 번째 행에 포커스 테두리가 자동으로 표시되지 않도록 수정했습니다. Tab 키 탐색은 계속 정상적으로 작동합니다.
