# バージョン %VERSION%（ビルド %BUILD%）

### 新機能

- 低電力モードの制御：バッテリー詳細に任意のスイッチを追加し、システム設定を開かずに低電力モードをオン／オフできます。初回は システム設定 › 一般 › ログイン項目と機能拡張 の「バックグラウンドでの実行を許可」で承認が必要です。登録されるヘルパーはこの操作だけを行い、アプリが使用している間だけ動作してアイドル状態になると自動終了します。承認の案内はスイッチの下に常に表示され、行全体をクリックするとログイン項目が開きます。
- リング満充電の基準：バッテリーリングを満充電とみなす充電レベルを選べます（50%〜100%、既定は 100%）。充電上限によって 100% 未満で止まる Mac に便利です。「充電上限を使用」で現在の上限をシステムから読み取ります。メニューバーと Dock が同時に反映されます。
- ローカル IP：ネットワーク設定の任意項目で、ネットワーク行の 2 行目にこの Mac のプライベート LAN アドレスを Wi-Fi 情報より前に表示します。既定はオフです。
- インターネット共有：Wi-Fi と有線の詳細ページから「共有」パネルを直接開き、インターネット共有をオンにできます。アプリはパネルを開くだけで、共有のオン／オフは行いません。

### 修正

- Wi-Fi 電波：CoreWLAN が一時的に返す無効な値を補うようにし、接続中のアイコンが急に薄くなったり 0 本になったりしなくなりました。
- Bluetooth デバイスのアイコン：デバイス自身が申告するクラス（device_minorType）だけで描画するようにし、接続・切断でアイコンが変わりません。メーカーがクラスを誤って定義している場合（例：キーボードがマウスとして申告される）はその定義どおりのアイコンを表示し、アプリ側で修正しません。
- メニューバーアイコン：スペースをドラッグしている間も、モノクロ部分の色がリアルタイムに切り替わります。
- アイコンの整列：SF Symbol をレイアウト枠ではなく実際のインクで中央揃えにし、リング上の Wi-Fi アイコンのずれを解消しました。
- オーディオ：重複していた音量出力の概要行を削除しました。

### 注意

- スペース切り替えのドラッグ中、完全にモノクロのアイコンのみが移動先のスペースに追従します。状態色を持つ要素（バッテリー低下、低電力モード、電源接続、Bluetooth）は切り替え確定後に更新されます。
