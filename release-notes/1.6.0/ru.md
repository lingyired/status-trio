# Версия %VERSION% (сборка %BUILD%)

### Новые возможности

- Управление режимом энергосбережения: необязательный переключатель в сведениях о батарее включает и выключает режим энергосбережения без открытия Системных настроек. Требуется однократное подтверждение в разделе Системные настройки › Основные › Объекты входа, в пункте «Разрешить в фоне»; регистрируемый помощник не делает ничего другого, работает только пока им пользуется приложение и завершается сам в простое. Подсказка о подтверждении остаётся под переключателем, а нажатие на всю строку открывает объекты входа.
- Уровень полного кольца: выберите уровень заряда, при котором кольцо батареи считается заполненным (50%–100%, по умолчанию 100%). Полезно на Mac, где ограничение заряда удерживает батарею ниже 100%; «Взять ограничение заряда» читает значение из системы. Строка меню и Dock следуют вместе.
- Локальный IP: необязательная настройка сети показывает частный адрес LAN этого Mac во второй строке строки сети, перед сведениями о Wi-Fi. По умолчанию выключено.
- Общий доступ к Интернету: страницы сведений о Wi-Fi и о кабеле могут открыть раздел «Общий доступ» напрямую, где включается общий доступ к Интернету. Приложение только открывает раздел и не включает общий доступ само.

### Исправления

- Сигнал Wi-Fi: кратковременные недействительные показания CoreWLAN теперь сглаживаются, поэтому подключённый значок больше не тускнеет и не показывает 0 делений.
- Значки Bluetooth-устройств: значок теперь рисуется только по классу, который заявляет само устройство (device_minorType), поэтому подключение и отключение его не меняют. Если производитель указал класс неверно — например, клавиатура представляется мышью — значок следует этому заявлению, и приложение его больше не исправляет.
- Значок в строке меню: монохромная часть перекрашивается в реальном времени, пока перетаскивается переключение пространства.
- Выравнивание значков: символы SF Symbol центрируются по видимым чернилам, а не по рамке макета, поэтому значок Wi-Fi больше не смещён относительно центра кольца.
- Аудио: удалена дублирующая строка сводки аудиовыхода.

### Примечания

- Пока перетаскивается переключение пространства, за целевым пространством следует только полностью монохромный значок; элементы с цветом состояния (низкий заряд, режим энергосбережения, питание от сети, Bluetooth) обновляются после завершения переключения.
