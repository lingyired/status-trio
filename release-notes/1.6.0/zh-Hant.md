# 版本 %VERSION%（組建 %BUILD%）

### 新功能

- 低耗電模式控制：電池詳細資訊中新增可選開關，無需開啟系統設定即可開關低耗電模式。首次需要在「系統設定 › 一般 › 登入項目與擴充功能」的「允許在背景執行」中批准一次；所註冊的輔助程式只做這件事，且只在 App 使用期間執行，閒置後自動結束。審批提示會一直顯示在該控制項下方，點按整列即可開啟登入項目。
- 圓環滿格電量：可自訂圓環視為滿格的電量（50%–100%，預設 100%），適合充電上限設定在 100% 以下的 Mac；點按「使用充電上限」可直接從系統讀取目前上限。選單列與 Dock 同時生效。
- 內網 IP：網路設定中可選擇在網路列第二行顯示本機內網 IP，位於 Wi-Fi 資訊之前，預設關閉。
- 互聯網共享：Wi-Fi 與有線的詳細資訊頁都可開啟「共享」面板，在其中開啟互聯網共享。App 只負責開啟面板，不代為開關。

### 修正

- Wi-Fi 訊號：橋接 CoreWLAN 偶發的無效讀數，已連線時圖示不再瞬間變淡或顯示 0 格。
- 藍牙裝置圖示：改為只按裝置自己宣告的類型（`device_minorType`）繪製，連線與中斷不再讓圖示跳動。若廠商在裝置裡把類型定義錯了（例如把鍵盤宣告為滑鼠），圖示會跟隨廠商的定義顯示，App 不再代為修正。
- 選單列圖示：拖曳切換空間時，單色部分會跟隨目標空間即時重新著色。
- 圖示對齊：修正 SF Symbol 按可見墨跡而非版面框置中，Wi-Fi 圖示在圓環上不再偏移。
- 音訊：移除重複的音量輸出摘要列。

### 說明

- 拖曳切換空間的整個過程中，只有單色圖示可以完全跟隨；帶狀態顏色（電量偏低、低耗電模式、已接電源、藍牙）的圖元仍需等切換完成後才更新。
