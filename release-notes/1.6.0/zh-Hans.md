# 版本 %VERSION%（构建 %BUILD%）

### 新功能

- 低电量模式控制：电池详情中新增可选开关，无需打开系统设置即可开关低电量模式。首次需要在「系统设置 › 通用 › 登录项与扩展」的“允许在后台”中批准一次；所注册的辅助程序只做这一件事，且只在应用使用期间运行，空闲后自动退出。审批提示始终显示在该控制项下方，点击整行即可打开登录项。
- 圆环满格电量：可自定义圆环视为满格的电量（50%–100%，默认 100%），适合充电上限设在 100% 以下的 Mac；点“使用充电上限”可直接从系统读取当前上限。菜单栏与程序坞同时生效。
- 内网 IP：网络设置中可选择在网络行第二行显示本机内网 IP，位于 Wi-Fi 信息之前，默认关闭。
- 互联网共享：Wi-Fi 与有线的详情页都可打开“共享”面板，在其中开启互联网共享。应用只负责打开面板，不代为开关。

### 修复

- Wi-Fi 信号：桥接 CoreWLAN 偶发的无效读数，已连接时图标不再瞬间变淡或显示 0 格。
- 蓝牙设备图标：改为只按设备自己声明的类型（`device_minorType`）绘制，连接与断开不再让图标跳变。若厂商在设备里把类型定义错了（例如把键盘声明为鼠标），图标会跟随厂商的定义显示，应用不再代为纠正。
- 菜单栏图标：拖拽切换空间时，单色部分会跟随目标空间实时重新着色。
- 图标对齐：修正 SF Symbol 按可见墨迹而非布局框居中，Wi-Fi 图标在圆环上不再偏移。
- 音频：去掉重复的音量输出摘要行。

### 说明

- 拖拽切换空间的整个过程中，只有单色图标可以完全跟随；带状态颜色（电量偏低、低电量模式、已接电源、蓝牙）的图元仍需等切换完成后才更新。
