# 버전 %VERSION% (빌드 %BUILD%)

### 새로운 기능

- 이제 macOS 13까지 지원합니다.
- 선택적 사용 통계를 추가했습니다. 기본값은 꺼짐이며 직접 켜야 합니다.
- Apple 기기 배터리: 연결된 iPhone을 통해 페어링된 Apple Watch의 배터리를 읽고, 신뢰하는 Apple 기기를 Bluetooth 목록의 통합된 행으로 표시합니다. 백그라운드 배터리 갱신과 갱신 간격 설정도 추가했습니다. 배터리는 패널에 표시되는 선택된 기기에서만 읽습니다.
- 이제 Bluetooth 오디오 아이콘을 사용자화할 수 있습니다.

### 개선 사항

- 아이콘과 상태 패널 업데이트 로직을 최적화했습니다.

### 수정 사항

- 아이콘 렌더링: 캐시된 비트맵 충실도, 안정적인 애니메이션 크기 조절, 충전 번개 하트비트 색상, 메뉴 막대와 Dock 정렬을 수정했습니다.
- 첫 Bluetooth 새로 고침 시 더 이상 설정이 실수로 열리지 않습니다.

### 개인정보

- 선택적 사용 통계, 하트비트에 포함되는 내용, 타사 분석 SDK가 포함되지 않았음을 설명합니다. 자세한 내용은 [개인정보 및 분석](https://github.com/lingyired/status-trio/blob/main/docs/privacy-telemetry.md)을 참조하세요.
