# バージョン %VERSION%（ビルド %BUILD%）

### バッテリーと電源

- バッテリー詳細に、システム最大容量・バッテリーの状態・システム稼働時間を表示するようにしました。
- 高電力モードは詳細で常に独立した分かりやすい行として表示され、状態は pmset から直接読み取ります。不明な健康状態や高電力状態は明示します。
- 「最適化されたバッテリー充電」が上限 100% で充電を一時停止している場合でも「今すぐ満充電」が機能するようになりました。要求は macOS 標準の方法で送信され、完了しても元の充電上限は復元されません（#292）。
- 詳細ページと設定ページで、「今すぐ満充電」が利用できない、または非表示になる理由を説明するようにしました（#280、#292）。
- 上限が 100% でも「最適化されたバッテリー充電」により充電が一時停止することがある旨を設定に追記しました（#292）。

### 明るさとディスプレイ

- 外部ディスプレイに「自動」の明るさバックエンドを追加しました。BetterDisplay 実行中はそれを使用し、それ以外は直接 DDC を使います。明示的に選んだバックエンドは記憶され、上書きされません。
- キーボード・コントロールセンター・システム設定による内蔵ディスプレイの明るさ変更が、パネルに即座に反映されるようになりました（#286）。
- パネル表示中は、外部ディスプレイの明るさを 2 秒間隔で更新し、キーボードでの変更もパネルに反映されます。
- DDC の明るさドラッグ時のカクつきを修正し、外部ディスプレイを正しく識別するようにしました（内蔵画面を外部として操作しない）（#284、#285）。

### Wi-Fi とネットワーク

- Clash Verge TUN の電源トグルを追加しました。Mihomo の読み取り専用 API で TUN を識別し、素のトンネルは「VPN」ではなく「TUN」と表示し、トグルの状態を同期します（#272）。
- Wi-Fi 概要行の電源スイッチの表示と、オフにする前の確認範囲を改善しました（#252）。

### 入力ソース

- Caps Lock と Shift を同時にオンにしたときに大文字が維持されない問題を修正し、インジケーターが正しく a/A を表示するようにしました（#279）。

### Bluetooth

- Bluetooth アイコンのカスタムカラーを追加しました（#275）。
- Bluetooth デバイスが切断された後、古いバッテリー残量が残らず失効するようにしました。

### パネルと設定

- バッテリー設定行のホバー装飾をクリック可能な範囲に合わせ、余白を追加しました（#281）。
- 電力フロー図の角丸カードを復元し、リボンのはみ出しをマスクしました（#282）。
- 設定の更新間隔を元のスライダーコンポーネントに戻しました（#255）。

### パフォーマンスと安定性

- 監視スレッドのライフタイムとポーリング間隔を引き締め、バックグラウンド負荷を抑えて安定性を高めました（#294）。
- オーディオデバイスの構成変更時に、キャッシュした出力デバイスを更新するようにしました（#293）。
- アイコン・パネル・設定・監視に関するパフォーマンスと安定性の問題を修正しました。
