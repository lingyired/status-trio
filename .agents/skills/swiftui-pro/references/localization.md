# Localization

- Add text through the project's current localization resources. Existing `.strings` and `.stringsdict` workflows should continue; moving them to a String Catalog requires an explicit request.
- When the project uses `Localizable.xcstrings` and generated string symbols are enabled, add each new user-facing string as a symbol key with `extractionState` set to `"manual"`, then use the generated symbol, such as `Text(.libraryEmpty)`. Otherwise, follow the project's existing string-key access. Offer translations for the new keys in all the project's languages.
- For new properties, parameters, and enum payloads carrying localizable interface text, prefer `LocalizedStringResource`, for example `let explanation: LocalizedStringResource`. This applies equally to views, models, and other supporting types. `Text` displays a plain `String` verbatim; converting a runtime string to `LocalizedStringKey` does not make Xcode extract it into the catalog. Existing custom-view parameters typed as `LocalizedStringKey` are valid, and changing existing `String` storage belongs outside unrelated work.
- Before iOS 26, `LabeledContent` and the plain `TextField(_:text:)` do not accept a `LocalizedStringResource` title, so give them a `Text` label made from the resource. The other `TextField` forms, with `prompt:`, `axis:`, or `value:format:`, accept a resource from iOS 16, as do `SecureField`, `Text`, `Button`, `Label`, `Toggle`, `Section`, `Picker`, and `navigationTitle()`.
- Within a package or framework, specify the containing bundle for localized text: `Text("Reading list", bundle: #bundle)`. Prefer `#bundle` because it also works in frameworks, where the Swift package accessor `Bundle.module` is unavailable. Omitting the bundle argument makes SwiftUI search the application's main bundle, which can silently leave text untranslated.
- Read locale, calendar, and time zone through the view environment: `@Environment(\.locale)`, `@Environment(\.calendar)`, and `@Environment(\.timeZone)`. Their `.current` counterparts do not respect preview or per-view overrides.
- Add translator comments for context-sensitive wording, such as whether "Record" names an item or starts a recording. Explain every interpolated placeholder. For generated symbol keys, store this guidance in the String Catalog.
